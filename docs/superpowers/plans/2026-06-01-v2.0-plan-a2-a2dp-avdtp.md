# v2.0 Plan A.2 — A2DP + AVDTP + SBC Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first end-to-end Classic audio demo: `Stack.virtual()` → `A2DPSource` ─AVDTP→ `A2DPSink` → SBC decode, in pure software, with the same plumbing usable on real hardware to push SBC to a Bluetooth speaker.

**Architecture:** Three new layers stacked on top of v1.0 + Plan A.1 codec foundation. **AVDTP** is the L2CAP-PSM-0x0019 transport with two channels per stream — a signaling channel (DISCOVER / GET_CAPABILITIES / SET_CONFIGURATION / OPEN / START / SUSPEND / CLOSE / ABORT) and a media transport channel carrying RTP-like SBC frames. **A2DP profile** is a thin wrapper exposing `A2DPSource` (sends PCM, internally SBC-encoded) and `A2DPSink` (receives + decodes), plus the two SDP service records. **VirtualClassicLink** gains a PSM-0x0019 bridge so the same code works under `Stack.virtual()` peer-to-peer. The AVDTP StreamEndpoint state machine reuses `pybluehost.core.statemachine.StateMachine`.

**Tech Stack:** Python 3.10+, asyncio, the `pybluehost.core.statemachine.StateMachine` framework, `pybluehost.audio.codec.SBCEncoder`/`SBCDecoder` from Plan A.1, the existing v1.0 `L2CAPManager`/`SDPServer`/`VirtualClassicLink`, pytest with `asyncio_mode=auto`.

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-27-prd-v2.0-classic-audio-design.md`](../specs/2026-05-27-prd-v2.0-classic-audio-design.md) — §3 Plan A.2 (lines 170-212), §4.1 A2DP source flow, §4.2 A2DP sink flow, §2.2 module layout

- **A2DP v1.4** — Advanced Audio Distribution Profile, §4.3 codec capabilities, §4.4 codec procedures

**Hard dependency:** Plan A.1 (codec foundation) must be merged. This plan imports `SBCEncoder` / `SBCDecoder` / `SBCHeader` from `pybluehost.audio.codec`.

**Scope discipline:** A.2 does **A2DP only**. AVRCP / AVCTP (Plan A.3) and HFP / HSP (A.4/A.5) reuse the same L2CAP infrastructure but live in separate plans — do not pull them in here.

Per AVDTP v1.3 §8.4, the signaling header in a single (non-fragmented) message is **2 bytes**:

```
Byte 0:  Transaction Label (4 bits) | Packet Type (2 bits) | Message Type (2 bits)
Byte 1:  Signal Identifier (6 bits, with 2 RFA upper bits = 0)
```

For START / CONTINUE / END (fragmented) packets the layout differs slightly — we cover SINGLE here; fragmentation in Task 7 (session level).

```python
"""AVDTP signaling layer — header + per-signal payload codec.

Reference: AVDTP v1.3 §8 (signaling procedures).
"""
from __future__ import annotations

from dataclasses import dataclass

from pybluehost.avdtp import constants as c


@dataclass(frozen=True)
class SignalingMessage:
    """An AVDTP signaling message in SINGLE-packet form.

    Fragmentation/reassembly (START/CONTINUE/END) is handled at the session
    layer (Task 7) — this dataclass represents a single, complete message.
    """

    transaction_label: int      # 0..15
    message_type: int           # MESSAGE_TYPE_*
    signal_id: int              # SIGNAL_* (6-bit; 1..0x3F)
    payload: bytes              # signal-specific body

    def __post_init__(self) -> None:
        if not 0 <= self.transaction_label <= 0x0F:
            raise ValueError(f"transaction_label {self.transaction_label} out of 0..15")
        if self.message_type not in (
            c.MESSAGE_TYPE_COMMAND, c.MESSAGE_TYPE_GENERAL_REJECT,
            c.MESSAGE_TYPE_RESPONSE_ACCEPT, c.MESSAGE_TYPE_RESPONSE_REJECT,
        ):
            raise ValueError(f"unknown message_type {self.message_type}")
        if not 1 <= self.signal_id <= 0x3F:
            raise ValueError(f"signal_id 0x{self.signal_id:02X} out of 1..0x3F")

    def to_bytes(self) -> bytes:
        header_byte = (
            (self.transaction_label << 4)
            | (c.PACKET_TYPE_SINGLE << 2)
            | self.message_type
        )
        signal_byte = self.signal_id & 0x3F
        return bytes([header_byte, signal_byte]) + self.payload

    @classmethod
    def from_bytes(cls, data: bytes) -> "SignalingMessage":
        if len(data) < 2:
            raise ValueError("AVDTP signaling message too short (need ≥ 2 bytes)")
        h = data[0]
        transaction_label = (h >> 4) & 0x0F
        packet_type = (h >> 2) & 0x03
        message_type = h & 0x03
        if packet_type != c.PACKET_TYPE_SINGLE:
            raise ValueError(
                f"AVDTP signaling: expected SINGLE packet but got fragment (packet_type={packet_type})"
            )
        signal_id = data[1] & 0x3F
        return cls(
            transaction_label=transaction_label,
            message_type=message_type,
            signal_id=signal_id,
            payload=bytes(data[2:]),
        )
```

AVDTP v1.3 §8.6 (DISCOVER): the response is a list of Stream End Point info entries. Each SEP entry is 2 bytes:

```
Byte 0: ACP SEID (6 bits) | In Use (1 bit) | RFA (1 bit) = 0
Byte 1: Media Type (4 bits) | TSEP (1 bit, 0=source 1=sink) | RFA (3 bits) = 0
```

AVDTP v1.3 §8.7 (GET_CAPABILITIES): command has 1 byte (target SEID); response has a list of Service Capability blocks:

```
Byte 0: Service Category (e.g. MEDIA_TRANSPORT=0x01, MEDIA_CODEC=0x07)
Byte 1: Length of Service Capability LOSC (N)
Byte 2..N+1: Capability-specific payload
```

For A2DP, the only categories we use in this Plan are MEDIA_TRANSPORT (LOSC=0) and MEDIA_CODEC (LOSC=variable per codec, for SBC it's 6 bytes).

```python
@dataclass(frozen=True)
class SepInfo:
    """AVDTP v1.3 §8.6 Stream End Point info (2 bytes on the wire)."""
    seid: int                    # 1..0x3E
    in_use: bool
    media_type: int              # MEDIA_TYPE_*
    tsep_is_sink: bool           # False = SRC, True = SNK


def encode_discover_response(seps: list[SepInfo]) -> bytes:
    out = bytearray()
    for sep in seps:
        if not 1 <= sep.seid <= c.MAX_SEID:
            raise ValueError(f"seid 0x{sep.seid:02X} out of 1..0x{c.MAX_SEID:02X}")
        byte0 = ((sep.seid & 0x3F) << 2) | ((1 if sep.in_use else 0) << 1)
        byte1 = ((sep.media_type & 0x0F) << 4) | ((1 if sep.tsep_is_sink else 0) << 3)
        out.extend([byte0, byte1])
    return bytes(out)


def decode_discover_response(data: bytes) -> list[SepInfo]:
    if len(data) % 2 != 0:
        raise ValueError(f"discover response length {len(data)} not multiple of 2")
    seps: list[SepInfo] = []
    for i in range(0, len(data), 2):
        b0, b1 = data[i], data[i + 1]
        seps.append(
            SepInfo(
                seid=(b0 >> 2) & 0x3F,
                in_use=bool((b0 >> 1) & 0x01),
                media_type=(b1 >> 4) & 0x0F,
                tsep_is_sink=bool((b1 >> 3) & 0x01),
            )
        )
    return seps


@dataclass(frozen=True)
class ServiceCapability:
    """AVDTP v1.3 §8.7 service-capability block."""
    category: int        # SERVICE_CATEGORY_*
    data: bytes


def encode_get_capabilities_command(acp_seid: int) -> bytes:
    if not 1 <= acp_seid <= c.MAX_SEID:
        raise ValueError(f"acp_seid 0x{acp_seid:02X} out of range")
    return bytes([(acp_seid & 0x3F) << 2])


def decode_get_capabilities_command(data: bytes) -> int:
    if len(data) != 1:
        raise ValueError(f"GET_CAPABILITIES command body length {len(data)} != 1")
    return (data[0] >> 2) & 0x3F


def encode_get_capabilities_response(caps: list[ServiceCapability]) -> bytes:
    out = bytearray()
    for cap in caps:
        if len(cap.data) > 0xFF:
            raise ValueError(f"service capability LOSC {len(cap.data)} exceeds 255")
        out.extend([cap.category, len(cap.data)])
        out.extend(cap.data)
    return bytes(out)


def decode_get_capabilities_response(data: bytes) -> list[ServiceCapability]:
    caps: list[ServiceCapability] = []
    i = 0
    while i < len(data):
        if i + 2 > len(data):
            raise ValueError("service capability block truncated (need ≥ 2 bytes)")
        category = data[i]
        losc = data[i + 1]
        if i + 2 + losc > len(data):
            raise ValueError(
                f"service capability block truncated: category=0x{category:02X} losc={losc}"
            )
        caps.append(ServiceCapability(category=category, data=bytes(data[i + 2:i + 2 + losc])))
        i += 2 + losc
    return caps
```

```python
    *, acp_seid: int, int_seid: int, capabilities: list[ServiceCapability],
```

```python
"""AVDTP Stream Endpoint state machine (AVDTP v1.3 §9.1)."""
from __future__ import annotations

from enum import Enum

from pybluehost.core.statemachine import StateMachine


class StreamEndpointState(Enum):
    IDLE = "idle"
    CONFIGURED = "configured"
    OPEN = "open"
    STREAMING = "streaming"
    CLOSING = "closing"


class StreamEndpointEvent(Enum):
    SET_CONFIGURATION = "set_configuration"
    OPEN = "open"
    START = "start"
    SUSPEND = "suspend"
    CLOSE = "close"
    ABORT = "abort"


def build_stream_endpoint_machine() -> StateMachine[StreamEndpointState, StreamEndpointEvent]:
    sm: StateMachine = StateMachine(
        name="avdtp_sep",
        initial=StreamEndpointState.IDLE,
    )
    # Normal flow
    sm.add_transition(StreamEndpointState.IDLE, StreamEndpointEvent.SET_CONFIGURATION,
                      StreamEndpointState.CONFIGURED)
    sm.add_transition(StreamEndpointState.CONFIGURED, StreamEndpointEvent.OPEN,
                      StreamEndpointState.OPEN)
    sm.add_transition(StreamEndpointState.OPEN, StreamEndpointEvent.START,
                      StreamEndpointState.STREAMING)
    sm.add_transition(StreamEndpointState.STREAMING, StreamEndpointEvent.SUSPEND,
                      StreamEndpointState.OPEN)
    sm.add_transition(StreamEndpointState.OPEN, StreamEndpointEvent.CLOSE,
                      StreamEndpointState.CLOSING)
    sm.add_transition(StreamEndpointState.STREAMING, StreamEndpointEvent.CLOSE,
                      StreamEndpointState.CLOSING)
    # ABORT from anywhere → IDLE
    for state in StreamEndpointState:
        if state == StreamEndpointState.IDLE:
            continue
        sm.add_transition(state, StreamEndpointEvent.ABORT, StreamEndpointState.IDLE)
    # CLOSING → IDLE after transport channel teardown (driven externally)
    sm.add_transition(StreamEndpointState.CLOSING, StreamEndpointEvent.ABORT,
                      StreamEndpointState.IDLE)
    return sm
```

```python
"""AVDTPSession — top-level peer session, owns signaling + transport channels."""
from __future__ import annotations

import asyncio
import logging
from typing import Any

from pybluehost.avdtp import constants as c
from pybluehost.avdtp._states import StreamEndpointEvent, build_stream_endpoint_machine
from pybluehost.avdtp.signaling import (
    SepInfo,
    ServiceCapability,
    SignalingMessage,
    decode_discover_response,
    decode_set_configuration_command,
    encode_discover_response,
    encode_get_capabilities_response,
    encode_set_configuration_command,
    decode_get_capabilities_command,
    encode_get_capabilities_command,
    decode_set_configuration_reject,
    encode_seid_command,
    decode_seid_command,
)

logger = logging.getLogger(__name__)


class AvdtpRejectError(Exception):
    """Raised when the peer rejects a signaling command."""
    def __init__(self, signal_id: int, error_code: int) -> None:
        super().__init__(f"AVDTP reject signal=0x{signal_id:02X} error=0x{error_code:02X}")
        self.signal_id = signal_id
        self.error_code = error_code


class AVDTPSession:
    def __init__(self, signaling_channel: Any, *, role: str = "initiator") -> None:
        if role not in ("initiator", "acceptor"):
            raise ValueError(f"role must be 'initiator' or 'acceptor', got {role!r}")
        self._sig = signaling_channel
        self._role = role
        self._next_transaction_label = 0
        self._pending: dict[int, asyncio.Future] = {}
        self._local_seps: dict[int, dict] = {}     # seid → {tsep_is_sink, media_type, sm, caps_config}
        self._sig.on_data(self._on_signaling_data)

    # ---- local SEP registry ----------------------------------------------

    def register_local_sep(
        self, *, seid: int, tsep_is_sink: bool, media_type: int,
        capabilities: list[ServiceCapability] | None = None,
    ) -> None:
        if not 1 <= seid <= c.MAX_SEID:
            raise ValueError(f"seid 0x{seid:02X} out of range")
        if seid in self._local_seps:
            raise ValueError(f"seid 0x{seid:02X} already registered")
        self._local_seps[seid] = {
            "tsep_is_sink": tsep_is_sink,
            "media_type": media_type,
            "sm": build_stream_endpoint_machine(),
            "advertised_caps": capabilities or [],
            "negotiated_caps": None,
        }

    # ---- initiator-side high-level API ----------------------------------

    async def discover(self, *, timeout: float = 5.0) -> list[SepInfo]:
        reply = await self._send_command(c.SIGNAL_DISCOVER, payload=b"", timeout=timeout)
        return decode_discover_response(reply.payload)

    async def get_capabilities(self, *, acp_seid: int, timeout: float = 5.0) -> list[ServiceCapability]:
        from pybluehost.avdtp.signaling import decode_get_capabilities_response
        reply = await self._send_command(
            c.SIGNAL_GET_CAPABILITIES,
            payload=encode_get_capabilities_command(acp_seid=acp_seid),
            timeout=timeout,
        )
        return decode_get_capabilities_response(reply.payload)

    async def set_configuration(
        self, *, acp_seid: int, int_seid: int,
        capabilities: list[ServiceCapability], timeout: float = 5.0,
    ) -> None:
        await self._send_command(
            c.SIGNAL_SET_CONFIGURATION,
            payload=encode_set_configuration_command(
                acp_seid=acp_seid, int_seid=int_seid, capabilities=capabilities
            ),
            timeout=timeout,
        )

    async def open(self, *, acp_seid: int, timeout: float = 5.0) -> None:
        await self._send_command(
            c.SIGNAL_OPEN, payload=encode_seid_command(acp_seid=acp_seid), timeout=timeout,
        )

    async def start(self, *, acp_seid: int, timeout: float = 5.0) -> None:
        await self._send_command(
            c.SIGNAL_START, payload=encode_seid_command(acp_seid=acp_seid), timeout=timeout,
        )

    async def suspend(self, *, acp_seid: int, timeout: float = 5.0) -> None:
        await self._send_command(
            c.SIGNAL_SUSPEND, payload=encode_seid_command(acp_seid=acp_seid), timeout=timeout,
        )

    async def close(self, *, acp_seid: int, timeout: float = 5.0) -> None:
        await self._send_command(
            c.SIGNAL_CLOSE, payload=encode_seid_command(acp_seid=acp_seid), timeout=timeout,
        )

    # ---- internal --------------------------------------------------------

    async def _send_command(
        self, signal_id: int, *, payload: bytes, timeout: float,
    ) -> SignalingMessage:
        label = self._next_transaction_label
        self._next_transaction_label = (self._next_transaction_label + 1) & 0x0F
        future: asyncio.Future[SignalingMessage] = asyncio.get_running_loop().create_future()
        self._pending[label] = future
        msg = SignalingMessage(
            transaction_label=label,
            message_type=c.MESSAGE_TYPE_COMMAND,
            signal_id=signal_id,
            payload=payload,
        )
        await self._sig.send(msg.to_bytes())
        try:
            reply = await asyncio.wait_for(future, timeout=timeout)
        finally:
            self._pending.pop(label, None)
        if reply.message_type == c.MESSAGE_TYPE_GENERAL_REJECT:
            raise AvdtpRejectError(signal_id, 0)
        if reply.message_type == c.MESSAGE_TYPE_RESPONSE_REJECT:
            # First byte of reject payload is the error code (or service category for SET_CONFIG).
            err = reply.payload[0] if reply.payload else 0
            raise AvdtpRejectError(signal_id, err)
        return reply

    async def _on_signaling_data(self, data: bytes) -> None:
        try:
            msg = SignalingMessage.from_bytes(data)
        except ValueError:
            logger.exception("AVDTP: malformed signaling frame")
            return
        if msg.message_type == c.MESSAGE_TYPE_COMMAND:
            await self._handle_command(msg)
        else:
            fut = self._pending.get(msg.transaction_label)
            if fut is not None and not fut.done():
                fut.set_result(msg)

    async def _handle_command(self, msg: SignalingMessage) -> None:
        sid = msg.signal_id
        if sid == c.SIGNAL_DISCOVER:
            seps = [
                SepInfo(seid=seid, in_use=False, media_type=info["media_type"],
                        tsep_is_sink=info["tsep_is_sink"])
                for seid, info in self._local_seps.items()
            ]
            await self._send_accept(msg, payload=encode_discover_response(seps))
        elif sid == c.SIGNAL_GET_CAPABILITIES:
            target = decode_get_capabilities_command(msg.payload)
            info = self._local_seps.get(target)
            if info is None:
                await self._send_reject(msg, payload=bytes([c.ERROR_BAD_ACP_SEID]))
                return
            await self._send_accept(
                msg, payload=encode_get_capabilities_response(info["advertised_caps"]),
            )
        elif sid == c.SIGNAL_SET_CONFIGURATION:
            acp, intseid, caps = decode_set_configuration_command(msg.payload)
            info = self._local_seps.get(acp)
            if info is None:
                await self._send_reject(msg, payload=bytes([0, c.ERROR_BAD_ACP_SEID]))
                return
            info["sm"].fire(StreamEndpointEvent.SET_CONFIGURATION)
            info["negotiated_caps"] = caps
            await self._send_accept(msg, payload=b"")
        elif sid in (c.SIGNAL_OPEN, c.SIGNAL_START, c.SIGNAL_SUSPEND, c.SIGNAL_CLOSE, c.SIGNAL_ABORT):
            target = decode_seid_command(msg.payload)
            info = self._local_seps.get(target)
            if info is None:
                await self._send_reject(msg, payload=bytes([c.ERROR_BAD_ACP_SEID]))
                return
            event = {
                c.SIGNAL_OPEN: StreamEndpointEvent.OPEN,
                c.SIGNAL_START: StreamEndpointEvent.START,
                c.SIGNAL_SUSPEND: StreamEndpointEvent.SUSPEND,
                c.SIGNAL_CLOSE: StreamEndpointEvent.CLOSE,
                c.SIGNAL_ABORT: StreamEndpointEvent.ABORT,
            }[sid]
            try:
                info["sm"].fire(event)
            except Exception:
                await self._send_reject(msg, payload=bytes([c.ERROR_BAD_STATE]))
                return
            await self._send_accept(msg, payload=b"")
        else:
            # Anything else → GENERAL_REJECT (AVDTP v1.3 §8.18).
            reject = SignalingMessage(
                transaction_label=msg.transaction_label,
                message_type=c.MESSAGE_TYPE_GENERAL_REJECT,
                signal_id=msg.signal_id,
                payload=b"",
            )
            await self._sig.send(reject.to_bytes())

    async def _send_accept(self, request: SignalingMessage, *, payload: bytes) -> None:
        accept = SignalingMessage(
            transaction_label=request.transaction_label,
            message_type=c.MESSAGE_TYPE_RESPONSE_ACCEPT,
            signal_id=request.signal_id,
            payload=payload,
        )
        await self._sig.send(accept.to_bytes())

    async def _send_reject(self, request: SignalingMessage, *, payload: bytes) -> None:
        reject = SignalingMessage(
            transaction_label=request.transaction_label,
            message_type=c.MESSAGE_TYPE_RESPONSE_REJECT,
            signal_id=request.signal_id,
            payload=payload,
        )
        await self._sig.send(reject.to_bytes())
```

```python
"""AVDTP media streaming — RTP-formatted SBC frames (A2DP v1.4 §4.4.1)."""
from __future__ import annotations

import struct
from dataclasses import dataclass


_RTP_VERSION = 0b10
_A2DP_PAYLOAD_TYPE = 96     # arbitrary in dynamic range; 96 is the conventional pick.


@dataclass(frozen=True)
class MediaPacket:
    sequence_number: int      # 16-bit
    timestamp: int            # 32-bit
    ssrc: int                 # 32-bit
    sbc_frames: list[bytes]   # variable count; SBC frame payloads (with their own 4B headers)


def encode_media_packet(pkt: MediaPacket) -> bytes:
    if not 0 <= pkt.sequence_number <= 0xFFFF:
        raise ValueError("sequence_number out of u16 range")
    if not 0 <= pkt.timestamp <= 0xFFFFFFFF:
        raise ValueError("timestamp out of u32 range")
    if not 0 <= pkt.ssrc <= 0xFFFFFFFF:
        raise ValueError("ssrc out of u32 range")
    n_frames = len(pkt.sbc_frames)
    if not 1 <= n_frames <= 0x0F:
        raise ValueError(f"sbc_frames count {n_frames} out of 1..15")
    header = struct.pack(
        ">BBHII",
        (_RTP_VERSION << 6),                    # V=2, P=0, X=0, CC=0
        _A2DP_PAYLOAD_TYPE,                     # M=0, PT=96
        pkt.sequence_number,
        pkt.timestamp,
        pkt.ssrc,
    )
    frame_count_byte = n_frames & 0x0F          # F/S/L bits left as 0 for Plan A.2.
    return header + bytes([frame_count_byte]) + b"".join(pkt.sbc_frames)


def decode_media_packet(data: bytes) -> MediaPacket:
    if len(data) < 13:
        raise ValueError(f"media packet too short ({len(data)} bytes)")
    b0 = data[0]
    if (b0 >> 6) & 0x03 != _RTP_VERSION:
        raise ValueError("invalid RTP version")
    pt = data[1] & 0x7F
    if pt != _A2DP_PAYLOAD_TYPE:
        raise ValueError(f"unsupported payload type {pt}")
    seq = int.from_bytes(data[2:4], "big")
    ts = int.from_bytes(data[4:8], "big")
    ssrc = int.from_bytes(data[8:12], "big")
    n_frames = data[12] & 0x0F
    frames_blob = data[13:]
    # Parse out SBC frames by reading each frame's header to know its length.
    from pybluehost.audio.codec import SBCHeader
    frames: list[bytes] = []
    offset = 0
    for _ in range(n_frames):
        if offset + 4 > len(frames_blob):
            raise ValueError("media packet truncated: SBC header incomplete")
        hdr = SBCHeader.from_bytes(frames_blob[offset:offset + 4])
        flen = hdr.frame_length()
        if offset + flen > len(frames_blob):
            raise ValueError(f"media packet truncated: frame {len(frames)} short")
        frames.append(bytes(frames_blob[offset:offset + flen]))
        offset += flen
    return MediaPacket(sequence_number=seq, timestamp=ts, ssrc=ssrc, sbc_frames=frames)
```

```python
"""A2DP Source + Sink (A2DP v1.4) — SBC-only in Plan A.2."""
from __future__ import annotations

from dataclasses import dataclass

from pybluehost.audio.codec import SBCEncoder
from pybluehost.avdtp import constants as c
from pybluehost.avdtp.signaling import ServiceCapability


# Conservative A2DP default capability set (all values the spec mandates as supported).
SBC_CAPABILITY_DEFAULT: dict = {
    "sample_freq": {16000, 32000, 44100, 48000},
    "channel_modes": {"mono", "dual", "stereo", "joint_stereo"},
    "blocks": {4, 8, 12, 16},
    "subbands": {4, 8},
    "allocations": {"loudness", "snr"},
    "min_bitpool": 2,
    "max_bitpool": 53,
}


# Bit positions per A2DP v1.4 §4.3.2 SBC media codec capability bitfields.
_SBC_FREQ_BITS = {16000: 0x80, 32000: 0x40, 44100: 0x20, 48000: 0x10}
_SBC_CHMODE_BITS = {"mono": 0x08, "dual": 0x04, "stereo": 0x02, "joint_stereo": 0x01}
_SBC_BLOCK_BITS = {4: 0x80, 8: 0x40, 12: 0x20, 16: 0x10}
_SBC_SUBBAND_BITS = {4: 0x08, 8: 0x04}
_SBC_ALLOC_BITS = {"snr": 0x02, "loudness": 0x01}


def build_sbc_media_codec_capability(caps: dict) -> ServiceCapability:
    """Construct the 6-byte SBC media codec capability per A2DP v1.4 §4.3.2."""
    freq = sum(_SBC_FREQ_BITS[f] for f in caps["sample_freq"])
    chmodes = sum(_SBC_CHMODE_BITS[m] for m in caps["channel_modes"])
    blocks = sum(_SBC_BLOCK_BITS[b] for b in caps["blocks"])
    subbands = sum(_SBC_SUBBAND_BITS[s] for s in caps["subbands"])
    allocs = sum(_SBC_ALLOC_BITS[a] for a in caps["allocations"])
    data = bytes([
        0x00,                                                     # Media Type audio << 4
        c.A2DP_CODEC_TYPE_SBC,
        (freq & 0xF0) | (chmodes & 0x0F),
        (blocks & 0xF0) | (subbands & 0x0C) | (allocs & 0x03),
        caps["min_bitpool"] & 0xFF,
        caps["max_bitpool"] & 0xFF,
    ])
    return ServiceCapability(category=c.SERVICE_CATEGORY_MEDIA_CODEC, data=data)


@dataclass(frozen=True)
class SBCConfig:
    sample_rate: int
    channel_mode: str
    blocks: int
    subbands: int
    allocation: str
    bitpool: int


# Conservative preference order — pick the A2DP "default" SBC config when both
# ends support it, then fall back to less-preferred combinations.
_PREFERENCE_ORDER = [
    (44100, "joint_stereo", 16, 8, "loudness", 53),
    (48000, "joint_stereo", 16, 8, "loudness", 53),
    (44100, "stereo",       16, 8, "loudness", 53),
    (32000, "joint_stereo", 16, 8, "loudness", 35),
    (16000, "mono",         16, 8, "loudness", 26),
]


def select_sbc_config(*, source: dict, sink: dict) -> SBCConfig:
    """Find the highest-preference SBC config supported by both source and sink."""
    common = {
        "sample_freq": source["sample_freq"] & sink["sample_freq"],
        "channel_modes": source["channel_modes"] & sink["channel_modes"],
        "blocks": source["blocks"] & sink["blocks"],
        "subbands": source["subbands"] & sink["subbands"],
        "allocations": source["allocations"] & sink["allocations"],
        "min_bitpool": max(source["min_bitpool"], sink["min_bitpool"]),
        "max_bitpool": min(source["max_bitpool"], sink["max_bitpool"]),
    }
    if common["min_bitpool"] > common["max_bitpool"]:
        raise ValueError("no common SBC config: bitpool ranges disjoint")
    for fr, ch, bl, sb, al, bp in _PREFERENCE_ORDER:
        if (fr in common["sample_freq"] and ch in common["channel_modes"]
                and bl in common["blocks"] and sb in common["subbands"]
                and al in common["allocations"]
                and common["min_bitpool"] <= bp <= common["max_bitpool"]):
            return SBCConfig(sample_rate=fr, channel_mode=ch, blocks=bl, subbands=sb,
                             allocation=al, bitpool=bp)
    raise ValueError("no common SBC config in the preference order")


class A2DPSource:
    """A2DP Source profile — sends PCM, internally SBC-encoded.

    Constructor takes a `stack` (the v1.0 Stack instance) and the codec list.
    `register_profile(stack, A2DPSource(...))` (Task 14) wires it up.
    """

    PROFILE_NAME = "A2DPSource"
    PSM = c.AVDTP_PSM

    def __init__(self, stack, *, supported_codecs=("SBC",),
                 sbc_capabilities: dict | None = None) -> None:
        if "SBC" not in supported_codecs:
            raise ValueError("Plan A.2 requires SBC in supported_codecs")
        self._stack = stack
        self._sbc_caps = sbc_capabilities or SBC_CAPABILITY_DEFAULT

    def advertised_capabilities(self) -> list[ServiceCapability]:
        return [
            ServiceCapability(category=c.SERVICE_CATEGORY_MEDIA_TRANSPORT, data=b""),
            build_sbc_media_codec_capability(self._sbc_caps),
        ]

    async def connect(self, *, peer_addr) -> "A2DPSourceSession":
        if self._stack is None:
            raise RuntimeError("A2DPSource has no stack — call stack.register_profile first")
        from pybluehost.profiles.classic.a2dp import A2DPSourceSession   # forward ref
        # ACL must already exist; profile assumes a previous connect_classic().
        # Open AVDTP signaling channel.
        signaling = await self._stack.l2cap.connect_classic_channel(
            handle=peer_addr.handle, psm=c.AVDTP_PSM,
        )
        from pybluehost.avdtp.session import AVDTPSession
        session = AVDTPSession(signaling, role="initiator")
        return A2DPSourceSession(self, session, peer_addr=peer_addr)


@dataclass
class A2DPSourceSession:
    """One connected source→sink session. State is implicit in the inner AVDTPSession."""
    source: A2DPSource
    avdtp: "AVDTPSession"     # forward — provided by A2DPSource.connect
    peer_addr: object

    async def negotiate_codec(self, prefer=("SBC",)) -> SBCConfig:
        seps = await self.avdtp.discover()
        # Find first sink SEP.
        sink_seps = [s for s in seps if s.tsep_is_sink]
        if not sink_seps:
            raise RuntimeError("peer has no sink SEPs")
        target = sink_seps[0]
        caps = await self.avdtp.get_capabilities(acp_seid=target.seid)
        # Pull out the SBC capability bytes.
        sbc_cap = next((cp for cp in caps if cp.category == c.SERVICE_CATEGORY_MEDIA_CODEC), None)
        if sbc_cap is None:
            raise RuntimeError("peer sink does not advertise a media codec")
        sink_dict = _parse_sbc_capability_bytes(sbc_cap.data)
        chosen = select_sbc_config(source=self.source._sbc_caps, sink=sink_dict)
        # SET_CONFIGURATION with chosen.
        cap_bytes = _sbc_config_to_capability_bytes(chosen)
        await self.avdtp.set_configuration(
            acp_seid=target.seid, int_seid=1,
            capabilities=[
                ServiceCapability(category=c.SERVICE_CATEGORY_MEDIA_TRANSPORT, data=b""),
                ServiceCapability(category=c.SERVICE_CATEGORY_MEDIA_CODEC, data=cap_bytes),
            ],
        )
        self._target_seid = target.seid
        self._sbc_config = chosen
        return chosen

    async def start(self) -> None:
        await self.avdtp.open(acp_seid=self._target_seid)
        # Open transport channel — caller (or stack) attaches it on l2cap signal.
        # For Plan A.2 we assume the L2CAPManager surfaces the second channel
        # via an `on_classic_channel_open` event the session subscribes to.
        # (Implementer wires this against the real L2CAPManager event surface.)
        await self.avdtp.start(acp_seid=self._target_seid)
        self._encoder = SBCEncoder(
            sample_rate=self._sbc_config.sample_rate,
            channels=1 if self._sbc_config.channel_mode == "mono" else 2,
            channel_mode=self._sbc_config.channel_mode,
            blocks=self._sbc_config.blocks, subbands=self._sbc_config.subbands,
            allocation=self._sbc_config.allocation, bitpool=self._sbc_config.bitpool,
        )
        self._seq = 0
        self._timestamp = 0

    async def send_pcm(self, pcm_chunk: bytes) -> None:
        from pybluehost.avdtp.streaming import MediaPacket
        # One frame per packet for Plan A.2 (frame_count_byte = 1).
        frame = self._encoder.encode(pcm_chunk)
        pkt = MediaPacket(
            sequence_number=self._seq & 0xFFFF,
            timestamp=self._timestamp & 0xFFFFFFFF,
            ssrc=0xCAFEBABE,
            sbc_frames=[frame],
        )
        await self.avdtp.send_media(pkt)
        self._seq += 1
        # PCM samples per frame: blocks × subbands × channels
        self._timestamp += (
            self._sbc_config.blocks * self._sbc_config.subbands
            * (1 if self._sbc_config.channel_mode == "mono" else 2)
        )

    async def stop(self) -> None:
        await self.avdtp.suspend(acp_seid=self._target_seid)
        await self.avdtp.close(acp_seid=self._target_seid)


def _parse_sbc_capability_bytes(data: bytes) -> dict:
    """Inverse of build_sbc_media_codec_capability — pull the bitfields back out."""
    if len(data) != 6:
        raise ValueError(f"SBC capability must be 6 bytes, got {len(data)}")
    freq_byte = data[2]
    block_byte = data[3]
    return {
        "sample_freq": {f for f, m in _SBC_FREQ_BITS.items() if freq_byte & m},
        "channel_modes": {m for m, b in _SBC_CHMODE_BITS.items() if freq_byte & b},
        "blocks": {b for b, m in _SBC_BLOCK_BITS.items() if block_byte & m},
        "subbands": {s for s, m in _SBC_SUBBAND_BITS.items() if block_byte & m},
        "allocations": {a for a, m in _SBC_ALLOC_BITS.items() if block_byte & m},
        "min_bitpool": data[4],
        "max_bitpool": data[5],
    }


def _sbc_config_to_capability_bytes(cfg: SBCConfig) -> bytes:
    return build_sbc_media_codec_capability({
        "sample_freq": {cfg.sample_rate},
        "channel_modes": {cfg.channel_mode},
        "blocks": {cfg.blocks},
        "subbands": {cfg.subbands},
        "allocations": {cfg.allocation},
        "min_bitpool": cfg.bitpool,
        "max_bitpool": cfg.bitpool,
    }).data
```

```python
class A2DPSink:
    """A2DP Sink — receives PCM via SBC decode + media packet stream."""

    PROFILE_NAME = "A2DPSink"
    PSM = c.AVDTP_PSM

    def __init__(self, stack, *, supported_codecs=("SBC",),
                 sbc_capabilities: dict | None = None) -> None:
        if "SBC" not in supported_codecs:
            raise ValueError("Plan A.2 requires SBC in supported_codecs")
        self._stack = stack
        self._sbc_caps = sbc_capabilities or SBC_CAPABILITY_DEFAULT
        self._on_pcm = None

    def on_pcm(self, cb) -> None:
        """Set a callback invoked with each decoded PCM chunk."""
        self._on_pcm = cb

    def _register_with_session(self, session) -> None:
        """White-box hook used by tests + Stack.register_profile (Task 14)."""
        caps = [
            ServiceCapability(category=c.SERVICE_CATEGORY_MEDIA_TRANSPORT, data=b""),
            build_sbc_media_codec_capability(self._sbc_caps),
        ]
        session.register_local_sep(
            seid=1, tsep_is_sink=True, media_type=c.MEDIA_TYPE_AUDIO,
            capabilities=caps,
        )
        # Wire on_media to decode incoming media packets.
        from pybluehost.audio.codec import SBCDecoder
        self._decoder = SBCDecoder()

        async def _handle_media(data: bytes) -> None:
            from pybluehost.avdtp.streaming import decode_media_packet
            pkt = decode_media_packet(data)
            for frame in pkt.sbc_frames:
                pcm = self._decoder.decode(frame)
                if self._on_pcm is not None:
                    await self._on_pcm(pcm)
        session.on_media(_handle_media)
```

```python
def _synth_pcm(duration_s: float, sample_rate: int = 44100,
                freq_hz: float = 440.0, amplitude: int = 16000) -> bytes:
    """Generate stereo int16 PCM (interleaved L,R) for `duration_s`."""
    n_samples = int(duration_s * sample_rate)

        assert cfg.sample_rate == 44100

        await session.start()
        pcm = _synth_pcm(duration_s=0.5)
        # Send in encoder-sized chunks.
        chunk_bytes = 2 * cfg.blocks * cfg.subbands * 2     # stereo
        for i in range(0, len(pcm), chunk_bytes):
            chunk = pcm[i:i + chunk_bytes]
            if len(chunk) < chunk_bytes:
                break       # ignore trailing partial chunk
            await session.send_pcm(chunk)
        await session.stop()

        # Wait briefly for the sink to drain.
        for _ in range(100):
            if len(sink_pcm) >= len(pcm) // 2:
                break
            await asyncio.sleep(0.01)

        # PSNR check
        n = min(len(pcm), len(sink_pcm)) // 2 - 80
        original = list(struct.unpack(f"<{len(pcm)//2}h", pcm))
        recovered = list(struct.unpack(f"<{len(sink_pcm)//2}h", bytes(sink_pcm)))
        err = [original[i + 80] - recovered[i + 80] for i in range(n)]
        mse = sum(e * e for e in err) / max(n, 1)
        psnr = 10 * math.log10((32767 ** 2) / max(mse, 1))
        assert psnr > 30, f"PSNR {psnr:.2f} dB below 30 dB threshold"
    finally:
        await src_stack.close()
        await sink_stack.close()
```
