> **Phase 2 re-brainstorm caveat** (design spec §11.9): the auto-pts repository changes over time. Verify against `auto-pts/auto-pts` upstream before implementing — file layouts, module names, and required exports may have shifted.

**Goal:** Glue PyBlueHost into autoptsclient as a new IUT project. After P.9, an operator runs `autoptsclient` against a host that has PyBlueHost's `pts-tester` listening, and ≥ 5 PTS GAP test cases pass automatically against the real PTS dongle. PyBlueHost no longer needs a human pressing MMI buttons.

**Architecture:**
- Create `auto_pts_project/pybluehost_iut/` at the repo root — a Python package autoptsclient imports as its IUT project descriptor.
- **iutctl.py**: starts / stops the IUT side. Spawns `pybluehost app pts-tester --listen=...` as a subprocess, waits for the READY BTP event, exposes `iut_init()` / `iut_cleanup()` per autoptsclient's IUT-control contract.
- **pics.py**: PICS dict (feature → True/False) per target test group. Generated from Phase 1's PICS draft YAML output + manually corrected.
- **ixit.py**: IXIT (test parameters) — BD address, role flags, IUT-specific values like passkey defaults.
- **wid/**: per-profile WID handler **adapters**. Most WID prompts are handled by upstream `autoptsclient/wid/*.py` which emit standard BTP commands. Subclass and override only the prompts where PyBlueHost behaves differently.
- **README.md**: operator runbook — how autoptsclient finds this project, how to start it, how to add new WID handlers.

**Tech Stack:** Python 3.10+, asyncio, subprocess (spawning `pts-tester`), pytest for the local sanity tests. **No new third-party deps in PyBlueHost itself** — the `auto_pts_project/` package depends on `autoptsclient` being installed alongside.

- [ ] **Step 1.5: Implement `iutctl.py`**

```python
"""IUT control hooks for autoptsclient.

autoptsclient calls iut_init() at session start and iut_cleanup() at end.
Between them, autoptsclient TCP-connects to the BTP tester port to send/receive
BTP frames.
"""
from __future__ import annotations

import asyncio
import logging
import os
import subprocess
import sys

logger = logging.getLogger(__name__)

# Module state — autoptsclient uses one project process at a time.
_subprocess: subprocess.Popen | None = None


async def iut_init(ctx) -> None:
    """Spawn `pybluehost app pts-tester` and wait until it accepts TCP connections.

    `ctx` is autoptsclient's run-time context dict. We pull:
      - ctx["listen"]: host:port the tester should listen on
      - ctx["transport"]: PyBlueHost transport spec (e.g. "virtual" or "usb")
    """
    global _subprocess
    listen = ctx.get("listen", "127.0.0.1:65103")
    transport = ctx.get("transport", "virtual")

    cmd = [
        sys.executable, "-m", "pybluehost", "app", "pts-tester",
        "-t", transport,
        f"--listen={listen}",
    ]
    logger.info("iut_init: spawning %s", " ".join(cmd))
    _subprocess = subprocess.Popen(
        cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
        close_fds=True,
        cwd=os.getcwd(),
    )

    # Wait for the tester to start listening — try connecting + reading the READY event.
    host, port_str = listen.rsplit(":", 1)
    port = int(port_str)
    deadline = asyncio.get_event_loop().time() + 30.0
    while True:
        if asyncio.get_event_loop().time() > deadline:
            raise RuntimeError(
                f"iut_init: timed out waiting for pts-tester on {listen}"
            )
        try:
            reader, writer = await asyncio.open_connection(host, port)
        except OSError:
            await asyncio.sleep(0.2)
            continue
        try:
            # Read 5 bytes of the BTP READY event header.
            header = await asyncio.wait_for(reader.readexactly(5), timeout=2.0)
            if header[0] == 0x00 and header[1] >= 0x80:
                logger.info("iut_init: tester ready, READY event received")
                break
        except (asyncio.TimeoutError, OSError, asyncio.IncompleteReadError):
            # Tester wasn't ready; retry.
            pass
        finally:
            writer.close()
            try:
                await writer.wait_closed()
            except Exception:
                pass
        await asyncio.sleep(0.2)


async def iut_cleanup(ctx) -> None:
    """Tear down the IUT subprocess."""
    global _subprocess
    if _subprocess is None:
        return
    try:
        _subprocess.terminate()
        try:
            _subprocess.wait(timeout=5.0)
        except subprocess.TimeoutExpired:
            _subprocess.kill()
            _subprocess.wait(timeout=2.0)
    except Exception:
        logger.exception("iut_cleanup: subprocess teardown failed")
    finally:
        _subprocess = None


def iut_log(*args, **kwargs) -> None:
    """autoptsclient calls this for run-time logging integration."""
    logger.info("autoptsclient: " + " ".join(str(a) for a in args))
```

```python
def yaml_draft_to_autopts_dict(yaml_path) -> dict[str, bool]:
    """Convert a Phase 1 PICS draft YAML to autoptsclient's flat dict format.

    Input YAML shape:
        GroupName:
          FEATURE_ID:
            supported: bool
            evidence: str

    Output: {FEATURE_ID: bool} flat dict (group key dropped — autoptsclient
    organizes PICS by per-group dict, not per-feature group prefix).
    """
    import yaml
    from pathlib import Path
    raw = yaml.safe_load(Path(yaml_path).read_text())
    # The top-level key is the group name (e.g. "GAP"); features are nested below.
    if not isinstance(raw, dict) or len(raw) != 1:
        raise ValueError(f"PICS YAML must have a single top-level group key: {yaml_path}")
    _, features = next(iter(raw.items()))
    return {feature: bool(info["supported"]) for feature, info in features.items()}
```

"""PICS — Protocol Implementation Conformance Statement for autoptsclient.

Each PICS_<GROUP> is a flat dict[FEATURE_ID, bool] that autoptsclient queries
when deciding which test cases apply.

Source of truth: `docs/pts/pics/<group>.draft.yaml` (generated by `pybluehost

from __future__ import annotations

from pathlib import Path

from pybluehost.pts.pics_gen import yaml_draft_to_autopts_dict


_REPO_ROOT = Path(__file__).resolve().parents[2]
_PICS_DIR = _REPO_ROOT / "docs" / "pts" / "pics"


def _load(group_name: str) -> dict[str, bool]:
    """Best-effort load of a group's PICS dict. Empty dict if file missing."""
    path = _PICS_DIR / f"{group_name.lower()}.draft.yaml"
    if not path.exists():
        return {}
    return yaml_draft_to_autopts_dict(path)


PICS_GAP = _load("GAP")
PICS_GATT = _load("GATT")
PICS_L2CAP = _load("L2CAP")
PICS_SMP = _load("SMP")
PICS_HCI = _load("HCI")
PICS_SDP = _load("SDP")     # not exercised by Phase 2 BTP, kept for completeness
PICS_RFCOMM = _load("RFCOMM")

```bash
#!/usr/bin/env bash
# Convenience launcher for autoptsclient against the PyBlueHost project.
#
# Required env vars / args:
#   --autoptsserver=<host>:<port>      Windows host running autoptsserver
#   --workspace=<path>                 PTS workspace path
# Optional:
#   --transport=virtual|usb           default: virtual
#   --listen=host:port                 default: 127.0.0.1:65103
set -euo pipefail

LISTEN="127.0.0.1:65103"
TRANSPORT="virtual"
AUTOPTSSERVER=""
WORKSPACE=""

for arg in "$@"; do
    case "$arg" in
        --autoptsserver=*) AUTOPTSSERVER="${arg#*=}" ;;
        --workspace=*)     WORKSPACE="${arg#*=}" ;;
        --transport=*)     TRANSPORT="${arg#*=}" ;;
        --listen=*)        LISTEN="${arg#*=}" ;;
        *) echo "unknown arg: $arg" >&2; exit 2 ;;
    esac
done

if [[ -z "$AUTOPTSSERVER" || -z "$WORKSPACE" ]]; then
    echo "usage: $0 --autoptsserver=<host>:<port> --workspace=<path> [--transport=...] [--listen=...]" >&2
    exit 2
fi

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../../.." && pwd)"
export PYTHONPATH="$REPO_ROOT/auto_pts_project:$PYTHONPATH"

# autoptsclient must be on PYTHONPATH from outside this script.
exec python -m autoptsclient \
    --project pybluehost_iut \
    --autoptsserver "$AUTOPTSSERVER" \
    --workspace "$WORKSPACE" \
    --iut-listen "$LISTEN" \
    --iut-transport "$TRANSPORT" \
    "$@"
```

Make it executable:

```bash

```
