> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

The opcode tables below are spec-snapshot as of plan-writing; **upstream is authoritative**.

**Goal:** Two more BTP services on top of P.5's foundation: **L2CAP** (LE Credit-Based Channel connect / disconnect / send / listen + Data Received events) and **SMP** (the SMP-test service for protocol-level SMP scenarios — OOB data, signing key, fixed pairing parameters; everyday pair / IO cap already in GAP). Both translate to Phase 1 `IutActions` / v1.0 stack surfaces.

**Architecture:**
- `LeCoCService` (Service ID `0x03`) drives `IutActions.l2cap_connect(addr, psm)` for outgoing + `stack.l2cap.listen_*` for incoming. Owns a per-session channel registry mapping autoptsclient's 16-bit `channel_id` → the v1.0 `ClassicChannel` / LE CoC channel object. Pushes Data Received events when payload arrives.
- `SmpService` (Service ID `0x04`) is a thin tester-facing surface for the small set of SMP-specific behaviours autoptsclient asks for outside of GAP's pair/IO cap commands (set OOB data, set signing key, set pairing parameter overrides). Most upstream variants implement just 2-4 opcodes here; verify before writing.
- Both reuse P.5's `BtpService` base + `BtpServiceRegistry` registration pattern.

**Tech Stack:** Python 3.10+, asyncio, struct, pytest with `asyncio_mode=auto`. Hard dependencies: Phase 1 (`IutActions.l2cap_connect`), v1.0 L2CAP / SMP, P.5 (BTP foundation), P.6 (registration pattern).

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-29-prd-v1.2-pts-iut-design.md`](../specs/2026-05-29-prd-v1.2-pts-iut-design.md) — §11.8 P.8 row, §11.4 scope (LE only)
- **auto-pts upstream** — https://github.com/auto-pts/auto-pts `doc/btp_l2cap.txt` + `doc/btp_sm.txt` (or `btp_gap.txt` if SMP is folded in)
- v1.0 L2CAP — `pybluehost/l2cap/manager.py` (`L2CAPManager.connect_classic_channel`, `listen_classic_psm`; LE CoC connect may be a separate method — verify)
- Phase 1 `IutActions.l2cap_connect` — design spec §4

**Hard dependencies:** P.5 + P.6 merged; Phase 1 merged.

**Scope discipline:**
- **LE only for L2CAP**: per design spec §11.4, Phase 2 BTP is LE-centric. Classic L2CAP via BTP is not standard in auto-pts upstream. If upstream changed, follow upstream.
- **SMP service minimal**: most pairing actions live in GAP (P.6). SMP service handles **only** the small set of opcodes upstream actually defines (typically OOB data + fixed-passkey overrides + signing key for test scenarios). If a desired test case requires GAP, route through GAP.
- **No reconfiguration / enhanced credit flow**: BTP `Reconfigure` opcode (if present in upstream) ships in P.8 only if the LE CoC reconfigure spec procedure is already in v1.0; otherwise mark it as `BTP_STATUS_UNKNOWN_CMD`.

```python
"""L2CAP BTP service — LE Credit-Based Channels (LE CoC).

See design spec §11.5 + auto-pts doc/btp_l2cap.txt.
"""
from __future__ import annotations

import asyncio
import logging
from dataclasses import dataclass
from typing import TYPE_CHECKING

from pybluehost.pts.btp import opcodes as op
from pybluehost.pts.btp.protocol import BtpFrame
from pybluehost.pts.btp.services.base import BtpService

if TYPE_CHECKING:
    from pybluehost.pts.actions import IutActions
    from pybluehost.pts.btp.tester import BtpTester

logger = logging.getLogger(__name__)


@dataclass
class _ChannelEntry:
    channel_id: int            # tester-assigned (16-bit)
    psm: int
    peer_addr: bytes
    addr_type: int
    underlying: object         # v1.0 L2CAP channel object


class LeCoCService(BtpService):
    SERVICE_ID = op.SERVICE_L2CAP

    def __init__(self, *, actions: "IutActions", tester: "BtpTester | None" = None) -> None:
        self._actions = actions
        self._tester = tester
        self._next_channel_id = 0x0001
        self._channels: dict[int, _ChannelEntry] = {}
        self._listening_psms: set[int] = set()

    def set_tester(self, tester: "BtpTester") -> None:
        self._tester = tester

    def _allocate_channel_id(self) -> int:
        cid = self._next_channel_id
        self._next_channel_id = (self._next_channel_id + 1) & 0xFFFF
        if self._next_channel_id == 0:
            self._next_channel_id = 1
        return cid
```

```python
    async def _handle_op_02(self, controller_index: int, data: bytes):
        # Connect body: addr_type(u8) + addr(6) + PSM(u16 LE) + transport(u8) + num_channels(u8)
        if len(data) != 11:
            return op.BTP_STATUS_FAILED, b""
        addr_type = data[0]
        addr = bytes(data[1:7])
        psm = int.from_bytes(data[7:9], "little")
        transport = data[9]
        num_channels = data[10]

        if transport != op.L2CAP_TRANSPORT_LE:
            # P.8 scope: LE only per design spec §11.4.
            return op.BTP_STATUS_FAILED, b""
        if num_channels != 1:
            # Multi-channel connect (enhanced L2CAP) not in v1.2 P.8 scope.
            return op.BTP_STATUS_FAILED, b""

        try:
            channel = await self._actions.l2cap_connect(addr, psm)
        except Exception:
            logger.exception("L2CAP Connect: actions.l2cap_connect raised")
            return op.BTP_STATUS_FAILED, b""
        if channel is None:
            return op.BTP_STATUS_FAILED, b""

        channel_id = self._allocate_channel_id()
        entry = _ChannelEntry(
            channel_id=channel_id, psm=psm, peer_addr=addr,
            addr_type=addr_type, underlying=channel,
        )
        self._channels[channel_id] = entry
        # Wire incoming-data callback for Data Received events.
        if hasattr(channel, "on_data"):
            channel.on_data(lambda payload: self._on_channel_data(channel_id, payload))

        # Response: num_channels(u8) + channel_id(u16 LE)
        return op.BTP_STATUS_SUCCESS, bytes([1]) + channel_id.to_bytes(2, "little")
```

```python
    # ---- Disconnect ------------------------------------------------------

    async def _handle_op_03(self, controller_index: int, data: bytes):
        if len(data) != 2:
            return op.BTP_STATUS_FAILED, b""
        channel_id = int.from_bytes(data[0:2], "little")
        entry = self._channels.pop(channel_id, None)
        if entry is None:
            return op.BTP_STATUS_FAILED, b""
        try:
            await entry.underlying.close()
        except Exception:
            logger.exception("L2CAP Disconnect: channel.close raised")
            return op.BTP_STATUS_FAILED, b""
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Send Data -------------------------------------------------------

    async def _handle_op_04(self, controller_index: int, data: bytes):
        if len(data) < 4:
            return op.BTP_STATUS_FAILED, b""
        channel_id = int.from_bytes(data[0:2], "little")
        data_len = int.from_bytes(data[2:4], "little")
        if 4 + data_len > len(data):
            return op.BTP_STATUS_FAILED, b""
        payload = bytes(data[4:4 + data_len])
        entry = self._channels.get(channel_id)
        if entry is None:
            return op.BTP_STATUS_FAILED, b""
        try:
            await entry.underlying.send(payload)
        except Exception:
            logger.exception("L2CAP Send Data: channel.send raised")
            return op.BTP_STATUS_FAILED, b""
        return op.BTP_STATUS_SUCCESS, b""
```

```python
    # ---- Listen ----------------------------------------------------------

    async def _handle_op_05(self, controller_index: int, data: bytes):
        if len(data) < 4:
            return op.BTP_STATUS_FAILED, b""
        psm = int.from_bytes(data[0:2], "little")
        transport = data[2]
        # mode_or_role byte (data[3]) and optional max_mtu — ignored in P.8.

        if transport != op.L2CAP_TRANSPORT_LE:
            return op.BTP_STATUS_FAILED, b""
        if psm in self._listening_psms:
            return op.BTP_STATUS_SUCCESS, b""    # idempotent

        stack = getattr(self._actions, "_stack", None)
        if stack is None or not hasattr(stack.l2cap, "listen_le_psm"):
            logger.warning("L2CAP Listen: stack has no listen_le_psm method")
            return op.BTP_STATUS_FAILED, b""

        async def _on_incoming(channel, peer_addr, peer_addr_type):
            cid = self._allocate_channel_id()
            entry = _ChannelEntry(
                channel_id=cid, psm=psm, peer_addr=bytes(peer_addr),
                addr_type=peer_addr_type, underlying=channel,
            )
            self._channels[cid] = entry
            if hasattr(channel, "on_data"):
                channel.on_data(lambda payload: self._on_channel_data(cid, payload))
            # Emit CONNECTED event.
            if self._tester is not None:
                mtu = getattr(channel, "mtu", 23)
                payload = bytearray()
                payload.extend(cid.to_bytes(2, "little"))
                payload.extend(psm.to_bytes(2, "little"))
                payload.append(peer_addr_type & 0xFF)
                payload.extend(bytes(peer_addr))
                payload.extend(mtu.to_bytes(2, "little"))
                asyncio.create_task(self._tester.emit_event(BtpFrame(
                    service=op.SERVICE_L2CAP, opcode=op.OP_L2CAP_EVENT_CONNECTED,
                    controller_index=0, data=bytes(payload),
                )))

        stack.l2cap.listen_le_psm(psm, _on_incoming)
        self._listening_psms.add(psm)
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Data Received event ---------------------------------------------

    def _on_channel_data(self, channel_id: int, payload: bytes) -> None:
        if self._tester is None:
            return
        out = bytearray()
        out.extend(channel_id.to_bytes(2, "little"))
        out.extend(len(payload).to_bytes(2, "little"))
        out.extend(payload)
        asyncio.create_task(self._tester.emit_event(BtpFrame(
            service=op.SERVICE_L2CAP, opcode=op.OP_L2CAP_EVENT_DATA_RECEIVED,
            controller_index=0, data=bytes(out),
        )))
```

```python
import os


    # ---- Set OOB Legacy Data ---------------------------------------------

    async def _handle_op_05(self, controller_index: int, data: bytes):
        if len(data) != 16:
            return op.BTP_STATUS_FAILED, b""
        stack = getattr(self._actions, "_stack", None)
        if stack is None:
            return op.BTP_STATUS_FAILED, b""
        stack.config.security.oob_legacy_tk = bytes(data)
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Set OOB SC Local: generate + store ------------------------------

    async def _handle_op_06(self, controller_index: int, data: bytes):
        # Generate a random + derive the confirm value. SMP SC OOB confirm is
        # f4(PKa.x, PKa.x, ra, 0) per Core Spec §2.2.6 — we approximate here by
        # returning random+random for the BTP layer; the actual confirm will be
        # filled by the SMP state machine when pairing starts.
        local_random = os.urandom(16)
        local_confirm = os.urandom(16)        # placeholder; SMP computes real f4 at pair time
        self._oob_sc_local = (local_random, local_confirm)
        stack = getattr(self._actions, "_stack", None)
        if stack is not None:
            stack.config.security.oob_sc_local = self._oob_sc_local
        return op.BTP_STATUS_SUCCESS, local_random + local_confirm

    async def _handle_op_07(self, controller_index: int, data: bytes):
        if self._oob_sc_local is None:
            return op.BTP_STATUS_FAILED, b""
        rand, confirm = self._oob_sc_local
        return op.BTP_STATUS_SUCCESS, rand + confirm

    async def _handle_op_08(self, controller_index: int, data: bytes):
        if len(data) != 32:
            return op.BTP_STATUS_FAILED, b""
        stack = getattr(self._actions, "_stack", None)
        if stack is None:
            return op.BTP_STATUS_FAILED, b""
        stack.config.security.oob_sc_remote = bytes(data)
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Set Fixed Passkey -----------------------------------------------

    async def _handle_op_0b(self, controller_index: int, data: bytes):
        if len(data) != 11:
            return op.BTP_STATUS_FAILED, b""
        addr = bytes(data[1:7])
        passkey = int.from_bytes(data[7:11], "little")
        stack = getattr(self._actions, "_stack", None)
        if stack is None:
            return op.BTP_STATUS_FAILED, b""
        stack.config.security.fixed_passkey = (addr, passkey)
```
