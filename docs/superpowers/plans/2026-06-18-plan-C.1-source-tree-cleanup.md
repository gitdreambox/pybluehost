## Task 1: Delete dead `pybluehost/transport/usb.py`

**Background:** A `pybluehost/transport/usb/` package was extracted from this module in commit `b1f181c`. Python now imports the package; the 97 KB module file has been dead since then. `uv run python -c "import pybluehost.transport.usb as u; print(u.__file__)"` resolves to the package, confirming the module is unreachable.

**Files:**
- Delete: `pybluehost/transport/usb.py`
- Test: full regression suite (no specific test file)

- [ ] **Step 1: Confirm the module is dead**

```bash
uv run python -c "import pybluehost.transport.usb as u; print(u.__file__)"
```

Expected output ends in `/pybluehost/transport/usb/__init__.py` (the package, not the `.py` file). If it ends in `usb.py`, STOP — re-verify before deleting.

- [ ] **Step 2: Confirm nothing imports the file directly**

```bash
grep -rn 'pybluehost\.transport\.usb\b' pybluehost/ tests/ --include="*.py" | grep -v __pycache__
```

All matches must be `pybluehost.transport.usb.<something>` (where `<something>` is a name re-exported from the package). No bare `pybluehost.transport.usb` followed by an empty/EOL.

- [ ] **Step 3: Delete the file**

```bash
git rm pybluehost/transport/usb.py
```

- [ ] **Step 4: Regression**

```bash
uv run pytest tests/ --transport=virtual --tb=short -q
```

Must show same pass count as before (1834 passed at master HEAD).

- [ ] **Step 5: Commit**

```bash
git commit -m "refactor(transport): delete dead usb.py (2537 lines, shadowed by usb/ package)"
```

## Task 2: Move `pybluehost/profiles/classic/test_at_parser.py` → `tests/`

**Background:** A test file lives inside the source package. `pyproject.toml` sets `testpaths = ["tests"]` but the file is still discovered by virtue of pytest's rootdir scan. More importantly, `pip install pybluehost` ships this test into the user's `site-packages`. Move it to the proper test tree.

**Files:**
- Move: `pybluehost/profiles/classic/test_at_parser.py` → `tests/unit/profiles/classic/test_at_parser.py`

- [ ] **Step 1: Verify the destination directory exists**

```bash
ls tests/unit/profiles/classic/ 2>&1 | head -3
```

If the directory exists, proceed. If not, create it and verify it isn't already covered by a different file name (rename if so).

- [ ] **Step 2: Check the import path inside the file is package-relative (already pybluehost.*)**

```bash
head -10 pybluehost/profiles/classic/test_at_parser.py
```

Confirm imports look like `from pybluehost.profiles.classic._at_parser import ...`. No relative `from .` imports — those would break after the move.

- [ ] **Step 3: Move with git so history follows**

```bash
git mv pybluehost/profiles/classic/test_at_parser.py tests/unit/profiles/classic/test_at_parser.py
```

- [ ] **Step 4: Run only the moved test, then full regression**

```bash
uv run pytest tests/unit/profiles/classic/test_at_parser.py -v
uv run pytest tests/ --transport=virtual --tb=short -q
```

Same pass count as Task 1's baseline.

- [ ] **Step 5: Commit**

```bash
git commit -m "test(profiles/classic): move test_at_parser.py to tests/ (was in source tree)"
```

## Task 3: Move `pybluehost/tools/gen_btsnoop_fixture.py` → `scripts/`

**Background:** `pybluehost/tools/` contains a single file: `gen_btsnoop_fixture.py`, a dev helper that regenerates a test fixture. It's not user-facing CLI code; the user-facing CLI lives in `pybluehost/cli/tools/` (info, fw, decode, usb, rpa, audio). Having both `pybluehost/tools/` and `pybluehost/cli/tools/` is confusing, and shipping a dev script in the published wheel is wasteful.

**Files:**
- Move: `pybluehost/tools/gen_btsnoop_fixture.py` → `scripts/gen_btsnoop_fixture.py`
- Delete: `pybluehost/tools/` directory (after move)

- [ ] **Step 1: Confirm `pybluehost/tools/` has only this one file**

```bash
ls pybluehost/tools/
```

Expected: `gen_btsnoop_fixture.py`. If there's more, STOP and ask — the cleanup scope changes.

- [ ] **Step 2: Search for references that assume the old path**

```bash
grep -rn 'pybluehost\.tools\.\|pybluehost/tools/' pybluehost/ tests/ docs/ --include="*.py" --include="*.md" 2>/dev/null | grep -v __pycache__
```

For each match, decide whether the reference should be updated (most likely yes, to `scripts/gen_btsnoop_fixture.py`) or removed (if doc references say "use this script…", update them).

- [ ] **Step 3: Create `scripts/` directory if missing, then move**

```bash
mkdir -p scripts
git mv pybluehost/tools/gen_btsnoop_fixture.py scripts/gen_btsnoop_fixture.py
```

- [ ] **Step 4: Remove the now-empty `pybluehost/tools/` directory**

```bash
rmdir pybluehost/tools
```

(If `rmdir` fails because of `__pycache__/` or `__init__.py`, look — the `__init__.py` was empty and we should `git rm` it.)

- [ ] **Step 5: Update any references found in Step 2**

For docs: change `pybluehost/tools/gen_btsnoop_fixture.py` → `scripts/gen_btsnoop_fixture.py`.

If there's a `python -m pybluehost.tools.gen_btsnoop_fixture` invocation anywhere, change to `python scripts/gen_btsnoop_fixture.py`.

- [ ] **Step 6: Regression**

```bash
uv run pytest tests/ --transport=virtual --tb=short -q
```

- [ ] **Step 7: Commit**

```bash
git add -A
git commit -m "refactor: move gen_btsnoop_fixture.py to scripts/ (dev helper, not user-facing)"
```
