# v2.0 Plan A.5 — HSP + SCO Loopback (CVSD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship HSP HS + AG roles by reusing everything Plan A.4 built (AT parser, RFCOMM, SCO data path, CVSD codec, VirtualClassicLink bridges). HSP is HFP minus codec negotiation and indicators, plus the volume-control AT commands (`AT+VGS` / `AT+VGM`) and the headset key event (`AT+CKPD`).

**Architecture:** Two small profile classes (`HSPClient`, `HSPServer`) and one set of SDP YAML records. Everything else is reused: the AT parser from Plan A.4 Task 1, the `WavToScoOutboundWorker` / `ScoToWavInboundWorker` workers from Plan A.4 Tasks 7-8, the HCI Setup_Synchronous_Connection command from Plan A.4 Task 6, the VirtualClassicLink HFP bridges from Plan A.4 Task 9. CVSD is the only HSP-supported codec — no `AT+BAC`, no `AT+BRSF`, no SLC handshake; the RFCOMM connection plus a one-shot exchange is the entire "service level" state.

**Tech Stack:** Python 3.10+, asyncio, stdlib `wave`, pytest with `asyncio_mode=auto`. No new third-party deps. Hard dependency on Plan A.4 (AT parser, SCO data path, VirtualClassicLink bridges).

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-27-prd-v2.0-classic-audio-design.md`](../specs/2026-05-27-prd-v2.0-classic-audio-design.md) — §3 Plan A.5 (lines 261-276)
- PRD: [`docs/PRD-v2.0.md`](../../PRD-v2.0.md) §3.4 HSP scope
- **HSP v1.2** — Headset Profile specification
  - §4.2 Service Discovery (service-class UUIDs HS=0x1108, AG=0x1112)
  - §4.6 AT command set (AT+CKPD, AT+VGS, AT+VGM, +VGS, +VGM, RING)
  - §4.7 Audio Connection (SCO setup — CVSD only)
- Bluetooth SIG Assigned Numbers — Headset = 0x1108, Headset Audio Gateway = 0x1112

**Hard dependencies:**
- **Plan A.4** — `_at_parser.py` (parse/format AT commands), `_sco_loopback.py` (`WavToScoOutboundWorker` / `ScoToWavInboundWorker`), `_hfp_state.CallState/CallEvent` is **not** reused (HSP has no call state machine), but `Stack.register_profile` flow is identical
- **Plan A.4 Task 6** — `HCIController.setup_sco` + `HCISetupSynchronousConnectionCommand` + `Synchronous_Connection_Complete` event
- **Plan A.4 Task 9** — VirtualClassicLink RFCOMM AT pass-through + HCI SCO bridges

**Scope discipline:**
- **Codec**: **CVSD only** (HSP v1.2 §4.7 mandates this; mSBC was added in HFP v1.6, not HSP).
- **AT command set**: only `AT+CKPD`, `AT+VGS`, `AT+VGM`, and the unsolicited responses `RING` / `+VGS:` / `+VGM:`. No CIND, no CMER, no BRSF, no BAC.
- **No call state machine**: HSP HS reports a single "button-press" (`AT+CKPD=200`) for accept/hangup; the AG interprets it contextually. No HFP-style call lifecycle.
- **No OS audio device**: file loopback only. Plan A.6 adds sounddevice.

```python
"""HSP v1.2 Headset Profile — Plan A.5.

HSPClient (HS) + HSPServer (AG). CVSD-only audio path; AT command set is the
strict HSP §4.6 subset: AT+CKPD, AT+VGS, AT+VGM, RING, +VGS:, +VGM:.
"""
from __future__ import annotations

from pybluehost.profiles.classic._at_parser import (
    ATCommand, ATResponse, format_at_command, parse_at_line,
)


# HSP v1.2 §6.3 — single feature bit on each side.
HSP_FEATURE_REMOTE_VOLUME_CONTROL = 0x0001

# HSP volume range is 0..15 inclusive (HSP v1.2 §4.6.1).
HSP_VOLUME_MIN = 0
HSP_VOLUME_MAX = 15

# AT+CKPD fixed argument (HSP v1.2 §4.6.3).
_CKPD_ARGUMENT = 200


def is_valid_ckpd_argument(value: int) -> bool:
    return value == _CKPD_ARGUMENT


def encode_ckpd_command() -> bytes:
    """HS → AG: AT+CKPD=200. Pressed once, interpretation contextual to AG state."""
    return format_at_command(ATCommand(name="+CKPD", args=[str(_CKPD_ARGUMENT)]))


def decode_ckpd_command(raw: bytes) -> int:
    parsed = parse_at_line(raw.decode("ascii"))
    if not isinstance(parsed, ATCommand) or parsed.name != "+CKPD":
        raise ValueError(f"not an AT+CKPD command: {raw!r}")
    if not parsed.args or len(parsed.args) != 1:
        raise ValueError(f"AT+CKPD requires exactly 1 argument: {raw!r}")
    arg = int(parsed.args[0])
    if not is_valid_ckpd_argument(arg):
        raise ValueError(
            f"AT+CKPD argument must be {_CKPD_ARGUMENT} per HSP v1.2 §4.6.3, got {arg}"
        )
    return arg
```

```python
def _validate_volume(value: int) -> int:
    if not HSP_VOLUME_MIN <= value <= HSP_VOLUME_MAX:
        raise ValueError(
            f"HSP volume {value} out of 0..15 (HSP v1.2 §4.6.1)"
        )
    return value


def encode_vgs_command(*, volume: int) -> bytes:
    _validate_volume(volume)
    return format_at_command(ATCommand(name="+VGS", args=[str(volume)]))


def decode_vgs_command(raw: bytes) -> int:
    parsed = parse_at_line(raw.decode("ascii"))
    if not isinstance(parsed, ATCommand) or parsed.name != "+VGS":
        raise ValueError(f"not an AT+VGS command: {raw!r}")
    return _validate_volume(int(parsed.args[0]))


def encode_vgm_command(*, volume: int) -> bytes:
    _validate_volume(volume)
    return format_at_command(ATCommand(name="+VGM", args=[str(volume)]))


def decode_vgm_command(raw: bytes) -> int:
    parsed = parse_at_line(raw.decode("ascii"))
    if not isinstance(parsed, ATCommand) or parsed.name != "+VGM":
        raise ValueError(f"not an AT+VGM command: {raw!r}")
    return _validate_volume(int(parsed.args[0]))


def encode_vgs_unsolicited(*, volume: int) -> bytes:
    _validate_volume(volume)

    _validate_volume(volume)

    if not isinstance(parsed, ATResponse) or parsed.name != "+VGM":
```

```python
import asyncio
import logging

from pybluehost.profiles.classic._at_parser import ATResult

logger = logging.getLogger(__name__)


class HSPClient:
    """HSP HS (Headset) role — sends button presses + receives RING/volume changes."""

    PROFILE_NAME = "HSPClient"
    SDP_RECORD = "hsp_hs.yaml"

    def __init__(self, rfcomm_channel) -> None:
        self._ch = rfcomm_channel
        self._buffer = bytearray()
        self._pending_result: asyncio.Future[bool] | None = None
        self._on_ring = None
        self._on_speaker_vol = None
        self._on_mic_vol = None
        rfcomm_channel.on_data(self._on_data)

    # ---- inbound callbacks ----------------------------------------------

    def on_ring(self, cb) -> None:
        self._on_ring = cb

    def on_speaker_volume(self, cb) -> None:
        self._on_speaker_vol = cb

    def on_microphone_volume(self, cb) -> None:
        self._on_mic_vol = cb

    # ---- outbound API ---------------------------------------------------

    async def press_button(self, *, timeout: float = 5.0) -> None:
        """Send AT+CKPD=200. AG interprets this contextually (accept/hangup)."""
        await self._exchange(encode_ckpd_command(), timeout=timeout)

    async def set_speaker_volume(self, *, volume: int, timeout: float = 5.0) -> None:
        await self._exchange(encode_vgs_command(volume=volume), timeout=timeout)

    async def set_microphone_volume(self, *, volume: int, timeout: float = 5.0) -> None:
        await self._exchange(encode_vgm_command(volume=volume), timeout=timeout)

    # ---- internal -------------------------------------------------------

    async def _exchange(self, payload: bytes, *, timeout: float) -> None:
        loop = asyncio.get_running_loop()
        self._pending_result = loop.create_future()
        await self._ch.send(payload)
        ok = await asyncio.wait_for(self._pending_result, timeout=timeout)
        if not ok:
            raise RuntimeError(f"HSP AG rejected command: {payload!r}")

    async def _on_data(self, data: bytes) -> None:
        self._buffer.extend(data)
        while True:
            idx = self._buffer.find(b"\r\n")
            if idx == -1:
                return
            if self._buffer.startswith(b"\r\n") and idx == 0:
                # Leading CRLF of an unsolicited response — find next CRLF.
                idx2 = self._buffer.find(b"\r\n", 2)
                if idx2 == -1:
                    return
                line = bytes(self._buffer[:idx2 + 2]).decode("ascii", errors="replace")
                del self._buffer[:idx2 + 2]
            else:
                line = bytes(self._buffer[:idx + 2]).decode("ascii", errors="replace")
                del self._buffer[:idx + 2]
            try:
                parsed = parse_at_line(line)
            except Exception:
                logger.exception("HSPClient: bad AT line %r", line)
                continue
            await self._dispatch(parsed)

    async def _dispatch(self, parsed) -> None:
        from pybluehost.profiles.classic._at_parser import ATResponse
        if isinstance(parsed, ATResult):
            if self._pending_result is not None and not self._pending_result.done():
                self._pending_result.set_result(parsed.ok)
                self._pending_result = None
        elif isinstance(parsed, ATResponse):
            if parsed.name == "RING":
                if self._on_ring is not None:
                    self._on_ring()
            elif parsed.name == "+VGS" and parsed.args:
                vol = int(parsed.args[0])
                if self._on_speaker_vol is not None:
                    self._on_speaker_vol(vol)
            elif parsed.name == "+VGM" and parsed.args:
                vol = int(parsed.args[0])
                if self._on_mic_vol is not None:
                    self._on_mic_vol(vol)
```

```python
from pybluehost.profiles.classic._at_parser import ATCommand, format_at_result, ATResult


class HSPServer:
    """HSP AG (Audio Gateway) role — accepts HS commands + emits RING/volume."""

    PROFILE_NAME = "HSPServer"
    SDP_RECORD = "hsp_ag.yaml"

    def __init__(self, rfcomm_channel) -> None:
        self._ch = rfcomm_channel
        self._buffer = bytearray()
        self._on_button = None
        self._on_speaker_vol = None
        self._on_mic_vol = None
        rfcomm_channel.on_data(self._on_data)

    # ---- inbound callbacks ----------------------------------------------

    def on_button(self, cb) -> None:
        self._on_button = cb

    def on_speaker_volume(self, cb) -> None:
        self._on_speaker_vol = cb

    def on_microphone_volume(self, cb) -> None:
        self._on_mic_vol = cb

    # ---- outbound API (AG-initiated unsolicited responses) --------------

    async def notify_ring(self) -> None:
        await self._ch.send(b"\r\nRING\r\n")

    async def notify_speaker_volume(self, *, volume: int) -> None:
        await self._ch.send(encode_vgs_unsolicited(volume=volume))

    async def notify_microphone_volume(self, *, volume: int) -> None:
        await self._ch.send(encode_vgm_unsolicited(volume=volume))

    # ---- internal -------------------------------------------------------

    async def _on_data(self, data: bytes) -> None:
        self._buffer.extend(data)
        while True:
            idx = self._buffer.find(b"\r\n")
            if idx == -1:
                return
            line = bytes(self._buffer[:idx + 2]).decode("ascii", errors="replace")
            del self._buffer[:idx + 2]
            try:
                parsed = parse_at_line(line)
            except Exception:
                logger.exception("HSPServer: bad AT line %r", line)
                continue
            if isinstance(parsed, ATCommand):
                await self._handle_command(parsed)

    async def _handle_command(self, cmd: ATCommand) -> None:
        if cmd.name == "+CKPD":
            try:
                arg = int(cmd.args[0]) if cmd.args else -1
                if not is_valid_ckpd_argument(arg):
                    await self._send_error()
                    return
            except (IndexError, ValueError):
                await self._send_error()
                return
            if self._on_button is not None:
                self._on_button()
            await self._send_ok()
        elif cmd.name == "+VGS":
            try:
                vol = _validate_volume(int(cmd.args[0]))
            except (IndexError, ValueError):
                await self._send_error()
                return
            if self._on_speaker_vol is not None:
                self._on_speaker_vol(vol)
            await self._send_ok()
        elif cmd.name == "+VGM":
            try:
                vol = _validate_volume(int(cmd.args[0]))
            except (IndexError, ValueError):
                await self._send_error()
                return
            if self._on_mic_vol is not None:
                self._on_mic_vol(vol)
            await self._send_ok()
        else:
            await self._send_error()

    async def _send_ok(self) -> None:
        await self._ch.send(format_at_result(ATResult(ok=True)))

    async def _send_error(self) -> None:
        await self._ch.send(format_at_result(ATResult(ok=False)))
```
