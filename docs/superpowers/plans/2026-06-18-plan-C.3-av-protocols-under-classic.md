# Plan C.3 — Relocate AV* Protocols Under `classic/`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use `- [ ]` syntax.

**Goal:** Move `pybluehost/avctp/`, `pybluehost/avdtp/`, `pybluehost/avrcp/` under `pybluehost/classic/`, where they architecturally belong. These three protocols are L2CAP-based and only used by Classic profiles (A2DP/AVRCP). Their top-level placement implies cross-stack reuse that doesn't exist.

**Architecture:** Pure file moves + import-path rewrite. No behaviour change. After move:

```
pybluehost/classic/
├── avctp/          (was pybluehost/avctp/)
├── avdtp/          (was pybluehost/avdtp/)
├── avrcp/          (was pybluehost/avrcp/)
├── gap.py
├── inquiry.py
├── rfcomm.py
├── sdp.py
└── ...
```

**Tech Stack:** `git mv` to preserve history; sed/Edit to rewrite imports.

**Risk:** This change touches ~15 import lines across `profiles/classic/`, `cli/app/`, and tests. A single missed import = ImportError on first import. Mitigation: run the full regression after each task.
