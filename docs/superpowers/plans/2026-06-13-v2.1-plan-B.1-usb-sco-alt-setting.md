# Plan v2.1-B.1 — USB SCO Alt-Setting + Vendor Quirks

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make HCI SCO data path work on USB hardware by adding Intel Alt-Setting switching, Realtek vendor command, and isoch IN/OUT endpoint I/O — the work explicitly deferred from v2.0 Plan A.6.

**Architecture:** Add a `prepare_for_sco(codec)` hook on the Transport interface (default no-op so virtual transport is unaffected). `HCIController.setup_synchronous_connection()` calls this hook before sending the HCI command. Each USB chip subclass implements its own variant: Intel selects an Alt Setting (1=CVSD, 6=mSBC), Realtek issues the `0xFC8B` vendor command. Generic isoch endpoint I/O lives on `USBTransport.base` and is shared by all chips.

**Tech Stack:** Python 3.10+ asyncio, pyusb (libusb backend), pytest + mock.

**Testability boundary:** All unit tests use mocked `usb.core.Device`. Real-hardware E2E verification is deferred until an Intel/Realtek adapter is available (this Plan does not include hardware execution; it preserves the existing "real hardware SCO verification pending" status).

```python
async def select_sco_alt_setting(self, alt: int) -> None:
    """Switch USB Interface 0 to alternate setting `alt`, then re-enumerate
    the iso IN/OUT endpoints. Alt 0 = SCO off (HCI events + ACL only).
    Higher alts have iso endpoints with vendor-specific packet sizes.
    """
    if getattr(self, "_current_alt_setting", 0) == alt:
        return
    import usb.util as usbutil
    self._device.set_interface_altsetting(interface=0, alternate_setting=alt)
    cfg = self._device.get_active_configuration()
    iface = cfg[(0, alt)]
    self._ep_iso_in = usbutil.find_descriptor(
        iface,
        custom_match=lambda e: (
            usbutil.endpoint_direction(e.bEndpointAddress) == usbutil.ENDPOINT_IN
            and usbutil.endpoint_type(e.bmAttributes) == usbutil.ENDPOINT_TYPE_ISO
        ),
    )
    self._ep_iso_out = usbutil.find_descriptor(
        iface,
        custom_match=lambda e: (
            usbutil.endpoint_direction(e.bEndpointAddress) == usbutil.ENDPOINT_OUT
            and usbutil.endpoint_type(e.bmAttributes) == usbutil.ENDPOINT_TYPE_ISO
        ),
    )
    self._current_alt_setting = alt
```

async def _read_iso_loop(self) -> None:
    while self._is_open and self._ep_iso_in is not None:
        try:
            data = await asyncio.get_event_loop().run_in_executor(
                None,
                lambda: bytes(self._ep_iso_in.read(1024, timeout=50)),
            )
            if self._sink is not None and data:
                await self._sink.on_transport_data(b"\x03" + data)
        except asyncio.CancelledError:
            break

RTK_SCO_ROUTING_HCI = 0x02

async def prepare_for_sco(self, codec: str) -> None:
    """Realtek: tell controller to route SCO via HCI bus (not PCM).
    Cached: only sends the vendor command on the first SCO setup.
    """
    if getattr(self, "_rtk_sco_routing_set", False):
        return

        HCI_VENDOR_RTK_SET_SCO_ROUTING_TYPE, bytes([RTK_SCO_ROUTING_HCI]),

    self._rtk_sco_routing_set = True
