> **Phase 2 re-brainstorm caveat** (design spec §11.9): verify auto-pts upstream `doc/btp_gap.txt` opcode numbering before implementing. The opcode tables below reflect upstream as of plan-writing 2026-06-01; auto-pts may have added/renumbered opcodes since.

> **Upstream-drift correction (2026-06-22, before T1):** Upstream `doc/btp_gap.txt` (verified via WebFetch) differs from this plan in opcodes 0x15–0x1A. Per upstream: `0x15` = Start Directed Advertising; `0x16` = Connection Parameters Update; `0x18` = OOB Legacy Set Data; `0x19` = OOB SC Get Local Data; `0x1a` = OOB SC Set Remote Data; `0x1b` = Set MITM; `0x1d` = Set Privacy. The plan's `OP_GAP_SET_PRIVACY=0x15` / `OP_GAP_SET_OOB_LEGACY=0x16` / `OP_GAP_SET_MITM=0x1A` are **WRONG against upstream and must not be defined as such**. Since P.6 scope (per plan task titles + PRD §9 NON-Goals) is core LE GAP and never touches Privacy/OOB/MITM, **drop those four constants entirely in T1**. Only define 0x01–0x14 + events 0x80–0x8B (those match upstream). Any later need for Privacy/OOB/MITM gets a separate task referencing upstream opcodes directly.

**Goal:** Implement the GAP BTP service so autoptsclient can drive PyBlueHost through every GAP test-case action: advertise / scan / connect / disconnect / pair / IO capability / passkey / bond, plus the event stream (Device Found / Connected / Disconnected / Passkey Request / Sec Level Changed). Adapter for Phase 1's `IutActions`.

**Architecture:** `GapService` subclasses `BtpService` (built in P.5), registers Service ID `0x01`, and routes opcodes to handlers that call into the Phase 1 `IutActions` layer. Each handler is one `async def _handle_op_XX(controller_index, data)` method that decodes the BTP command body, calls one `IutActions` method, encodes the response. GAP **events** are pushed to autoptsclient via `BtpTester.emit_event(...)` — the GAP service subscribes to `stack.on_connection_event` (and other v1.0 hooks) and synthesizes the corresponding BTP event frame. **No new protocol-stack code** — P.6 is purely a translation layer.

**Tech Stack:** Python 3.10+, asyncio, struct, pytest with `asyncio_mode=auto`. Hard dependency on Phase 1 (`IutActions`) + P.5 (`BtpService` / `BtpTester` / opcode constants).

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-29-prd-v1.2-pts-iut-design.md`](../specs/2026-05-29-prd-v1.2-pts-iut-design.md) — §11.8 P.6 row
- **auto-pts upstream** — https://github.com/auto-pts/auto-pts `doc/btp_gap.txt` (authoritative opcode + frame layout)
- Phase 1 `IutActions` — design spec §4 + plan `2026-05-31-v1.2-pts-iut-phase1.md` Tasks 6-10

**Hard dependencies:**
- P.5 (BTP foundation) merged
- Phase 1 (`IutActions`) merged — P.6 calls `actions.advertise()` / `actions.scan()` / `actions.connect()` / `actions.disconnect()` / `actions.pair()` / `actions.set_io_cap()`

**Scope discipline:**
- **LE only**: GAP service covers LE GAP commands. Classic Bluetooth discoverable/connectable bits exist in the BTP spec but PyBlueHost's Classic GAP is exercised via Phase 1 REPL — autoptsclient doesn't generate Classic test traffic.
- **Single controller**: PyBlueHost is one BT controller; `controller_index = 0` everywhere. We accept any value from autoptsclient but always operate on the stack's single controller.
- **Read Supported Commands** (opcode 0x01) returns the bitfield derived from `BtpService.supported_commands()` — auto-introspection from `_handle_op_XX` methods.
- **No SMP / OOB / Privacy**: GAP service exposes IO capability + passkey display/entry + bond. SMP-specific BTP service (P.8) covers anything beyond that.

```python
    # ---- Read Controller Index List ----------------------------------------

    async def _handle_op_02(self, controller_index: int, data: bytes):
        # Single-controller: index 0.
        return op.BTP_STATUS_SUCCESS, bytes([1, 0])

    # ---- Read Controller Information ---------------------------------------

    async def _handle_op_03(self, controller_index: int, data: bytes):
        # auto-pts upstream layout (verify against btp_gap.txt):
        #   [BD_ADDR(6)] [supported_settings(4 LE)] [current_settings(4 LE)]
        #   [class_of_device(3)] [name(249, NUL-padded)] [short_name(11, NUL-padded)]
        local_addr = getattr(self._actions, "local_address", None)
        if local_addr is None:
            addr_bytes = bytes(6)
        else:
            addr_bytes = _encode_bd_addr(local_addr)

        # Supported_settings: PyBlueHost supports BLE + connectable + bondable +
        # advertising. (bits per auto-pts spec; verify before final commit.)
        supported_settings = 0
        for bit in (1, 4, 8, 9):   # connectable, bondable, ble, advertising
            supported_settings |= (1 << bit)
        current_settings = self._current_settings

        out = bytearray()
        out.extend(addr_bytes)
        out.extend(supported_settings.to_bytes(4, "little"))
        out.extend(current_settings.to_bytes(4, "little"))
        out.extend(bytes(3))            # class_of_device — 0 for v1.2
        # 249-byte name + 11-byte short name
        name = b"PyBlueHost"
        out.extend(name.ljust(249, b"\x00"))
        out.extend(name[:11].ljust(11, b"\x00"))
        return op.BTP_STATUS_SUCCESS, bytes(out)

    # ---- Reset -------------------------------------------------------------

    async def _handle_op_04(self, controller_index: int, data: bytes):
        self._current_settings = 0
        return op.BTP_STATUS_SUCCESS, b""

    async def reset(self) -> None:
        """Called by Core's Reset Board across all registered services."""
        await self._handle_op_04(controller_index=0, data=b"")
```

```python
    # ---- Set Powered / Connectable / Fast Connectable / Discoverable / Bondable ----

    _SETTINGS_BITS = {
        op.OP_GAP_SET_POWERED: 0,
        op.OP_GAP_SET_CONNECTABLE: 1,
        op.OP_GAP_SET_FAST_CONNECTABLE: 2,
        op.OP_GAP_SET_DISCOVERABLE: 3,
        op.OP_GAP_SET_BONDABLE: 4,
    }

    def _set_settings_bit(self, opcode: int, value: int) -> bytes:
        bit = self._SETTINGS_BITS[opcode]
        if value:
            self._current_settings |= (1 << bit)
        else:
            self._current_settings &= ~(1 << bit)
        return self._current_settings.to_bytes(4, "little")

    async def _handle_op_05(self, controller_index: int, data: bytes):
        if len(data) != 1:
```

```python
    async def _handle_op_0a(self, controller_index: int, data: bytes):
        # adv_data_len + adv_data + scan_rsp_len + scan_rsp + duration(u32) + own_addr_type(u8)
        if len(data) < 1:

        offset = 0
        adv_data_len = data[offset]; offset += 1
        if offset + adv_data_len > len(data):
            return op.BTP_STATUS_FAILED, b""
        adv_data = data[offset:offset + adv_data_len]; offset += adv_data_len
        if offset >= len(data):

        scan_rsp_len = data[offset]; offset += 1
        if offset + scan_rsp_len > len(data):

        offset += scan_rsp_len
        # duration + own_addr_type tail (don't parse fully in P.6 — just verify presence)

            await self._actions.advertise(data=bytes(adv_data))
        except Exception:
            logger.exception("GAP Start Advertising: actions.advertise raised")
            return op.BTP_STATUS_FAILED, b""
```

```python
        # Detach scan callback locally so no further DEVICE_FOUND events fire.
        if hasattr(self._actions, "_scan_callback"):

        return op.BTP_STATUS_SUCCESS, b""

    def _on_scan_result(self, addr, addr_type: int, rssi: int, eir: bytes) -> None:
```

```python
    # ---- Connect / Disconnect ---------------------------------------------

    async def _handle_op_0e(self, controller_index: int, data: bytes):
        if len(data) != 7:
            return op.BTP_STATUS_FAILED, b""
        addr_type = data[0]
        addr = bytes(data[1:7])
        try:
            await self._actions.connect(_decode_bd_addr(addr), le=True)
        except Exception:
            logger.exception("GAP Connect: actions.connect raised")
            return op.BTP_STATUS_FAILED, b""
        return op.BTP_STATUS_SUCCESS, b""

    async def _handle_op_0f(self, controller_index: int, data: bytes):
        if len(data) != 7:
            return op.BTP_STATUS_FAILED, b""
        # Disconnect by address — translate to handle via session.
        addr = bytes(data[1:7])
        try:
            # Find the matching ConnInfo in IutActions session.
            session = self._actions.status()
            target_handle = None
            for h, info in session.connections.items():
                if _encode_bd_addr(info.peer) == addr:
                    target_handle = h
                    break
            if target_handle is None:
                return op.BTP_STATUS_FAILED, b""
            await self._actions.disconnect(target_handle)
        except Exception:
            logger.exception("GAP Disconnect: actions.disconnect raised")
            return op.BTP_STATUS_FAILED, b""
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Connection state events ------------------------------------------

    def on_connection_state_change(
        self, *, handle: int, addr: bytes, addr_type: int, connected: bool,
    ) -> None:
        """Hooked into stack.on_connection_event by `set_tester()` or at construction.

        For incoming connections (peripheral side), this fires with connected=True;
        for outgoing (central), it also fires after connect() completes.
        """
        if self._tester is None:

        # Payload: addr_type(u8) + addr(6) + [connected events also include conn_params...]

        if connected:
            # Append conn_params placeholder: interval(u16) + latency(u16) + timeout(u16)
            payload.extend(b"\x00" * 6)
        asyncio.create_task(self._tester.emit_event(BtpFrame(
            service=op.SERVICE_GAP, opcode=opcode,
```

```python
        # Passkey Confirm Reply: addr_type(u8) + addr(6) + match(u8)
        if len(data) != 8:
            return op.BTP_STATUS_FAILED, b""
        match = bool(data[7])
        confirm_fn = getattr(self._actions, "confirm_passkey", None)
        if confirm_fn is None:
            return op.BTP_STATUS_FAILED, b""
        try:
            await confirm_fn(match)
        except Exception:
            logger.exception("GAP Passkey Confirm Reply raised")
            return op.BTP_STATUS_FAILED, b""
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Pairing events ---------------------------------------------------

    def on_pairing_failed(self, *, addr: bytes, addr_type: int, reason: int) -> None:
        if self._tester is None:
            return
        payload = bytes([addr_type & 0xFF]) + bytes(addr) + bytes([reason & 0xFF])
        asyncio.create_task(self._tester.emit_event(BtpFrame(
            service=op.SERVICE_GAP, opcode=op.OP_GAP_EVENT_PAIRING_FAILED,
            controller_index=self._controller_index, data=payload,
        )))

    def on_sec_level_changed(self, *, addr: bytes, addr_type: int, sec_level: int) -> None:
        if self._tester is None:
            return
        payload = bytes([addr_type & 0xFF]) + bytes(addr) + bytes([sec_level & 0xFF])
        asyncio.create_task(self._tester.emit_event(BtpFrame(
            service=op.SERVICE_GAP, opcode=op.OP_GAP_EVENT_SEC_LEVEL_CHANGED,
            controller_index=self._controller_index, data=payload,
        )))

    def on_passkey_display(self, *, addr: bytes, addr_type: int, passkey: int) -> None:
        if self._tester is None:
            return
        payload = (
            bytes([addr_type & 0xFF]) + bytes(addr)
            + passkey.to_bytes(4, "little")
        )
        asyncio.create_task(self._tester.emit_event(BtpFrame(
            service=op.SERVICE_GAP, opcode=op.OP_GAP_EVENT_PASSKEY_DISPLAY,
            controller_index=self._controller_index, data=payload,
        )))
```

```python
import asyncio

import pytest

from pybluehost.pts.actions import IutActions
from pybluehost.pts.btp import (
    BTP_HEADER_SIZE, BtpFrame, BtpServiceRegistry, BtpTester, CoreService,
    decode_btp_frame, encode_btp_frame, opcodes as op,
)
from pybluehost.pts.btp.services.gap import GapService
from pybluehost.stack import Stack


async def _read_frame(reader):
    header = await reader.readexactly(BTP_HEADER_SIZE)
    data_len = int.from_bytes(header[3:5], "little")
    body = await reader.readexactly(data_len) if data_len else b""
    return decode_btp_frame(header + body)


async def test_btp_gap_advertise_via_bridge(unused_tcp_port):
    """End-to-end: TCP client → BtpTester → GapService → IutActions → virtual stack
    starts advertising. We verify by reading current_settings bit 9."""
    stack = await Stack.virtual()
    try:
        actions = IutActions(stack)
        reg = BtpServiceRegistry()
        reg.register(CoreService(registry=reg))
        gap = GapService(actions=actions)
        reg.register(gap)
        tester = BtpTester(registry=reg, host="127.0.0.1", port=unused_tcp_port)
        await tester.start()
        gap.set_tester(tester)
        try:
            reader, writer = await asyncio.open_connection("127.0.0.1", unused_tcp_port)
            await _read_frame(reader)         # consume READY event

            # Send Start Advertising
            adv_data = b"\x02\x01\x06"        # minimum flags AD
            body = bytes([len(adv_data)]) + adv_data + bytes([0]) + (0).to_bytes(4, "little") + bytes([0])
            writer.write(encode_btp_frame(BtpFrame(
                service=op.SERVICE_GAP, opcode=op.OP_GAP_START_ADVERTISING,
                controller_index=0, data=body,
            )))
            await writer.drain()
            resp = await _read_frame(reader)
            assert resp.data[0] == op.BTP_STATUS_SUCCESS
            # The 4-byte current_settings payload has bit 9 set.
            settings = int.from_bytes(resp.data[1:5], "little")
            assert settings & (1 << 9), f"advertising bit not set in 0x{settings:08X}"
            writer.close()
            await writer.wait_closed()
        finally:
            await tester.stop()
    finally:
        await stack.close()
```
