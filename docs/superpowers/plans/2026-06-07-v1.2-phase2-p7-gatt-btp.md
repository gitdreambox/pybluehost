> **Events**: only TWO event opcodes upstream — `0x80 = Notification/Indication Received` (one combined opcode; payload type byte distinguishes), `0x81 = Attribute Value Changed`. **Drop** the plan's separate `OP_GATT_NOTIFY = 0x1A` / `OP_GATT_INDICATE = 0x1B` server-push command constants (they don't exist) and the separate `OP_GATT_EVENT_INDICATION` constant.
>
> **Scope for P.7 v1**: P.7 implements opcodes 0x01-0x1B (server build + core client ops + CFG_NOTIFY/INDICATE) + events 0x80/0x81. Out of P.7 v1 scope: SIGNED_WRITE_WITHOUT_RSP (0x16), GET_ATTRIBUTES (0x1c), GET_ATTRIBUTE_VALUE (0x1d) — these are rarely exercised by PTS test cases and can be added later if needed.
>
> **T4 redirection**: the plan's T4 implements `OP_GATT_NOTIFY = 0x1A` / `OP_GATT_INDICATE = 0x1B` server-push handlers — but upstream defines those slots as `CFG_NOTIFY` / `CFG_INDICATE` (client subscribe commands, owned by T8). Upstream has NO explicit server-push opcode. **T4 must redirect** to implementing the `0x81 Attribute Value Changed` event emission: when 0x06 SET_VALUE is handled (or in future when a peer writes to a characteristic), the GattService synthesises a 0x81 event payload `[handle(u16 LE), data_len(u16 LE), data]` and pushes it to autoptsclient via `tester.emit_event(...)`. **Drop the plan's `_handle_op_1a` / `_handle_op_1b` notify/indicate code in T4** — those opcode slots belong to T8.

**Goal:** Implement the GATT BTP service so autoptsclient can drive PyBlueHost as both **GATT server** (dynamically add services / characteristics / descriptors, push notifications/indications) and **GATT client** (discover, read, write, subscribe). This is the single largest service in BTP — GATT test cases dominate PTS conformance testing.

**Architecture:** `GattService` subclasses `BtpService` (P.5), registers Service ID `0x02`, and routes opcodes to handlers in two groups:
- **Server-side** (build a GATT db on demand): autoptsclient calls Add Service → Add Characteristic → Add Descriptor → Set Value → Start Server, then Notify/Indicate. `GattService` keeps a per-session attribute-handle map (BTP handles are tester-assigned; the BTP service translates to/from the v1.0 GATT server's internal handles).
- **Client-side** (drive an existing GATTClient from `IutActions.connect()`): autoptsclient calls Exchange MTU / Discover / Read / Write / Configure Notify, against the connection identified by address. `GattService` resolves address→handle→GATTClient via the Phase 1 `IutActions` session.
- **Events** (≥ 0x80): Notification received / Indication received / Attribute Value Changed are pushed via `BtpTester.emit_event`.

**Tech Stack:** Python 3.10+, asyncio, struct, pytest. Hard dependency on Phase 1 (`IutActions`) + P.5 (BTP foundation) + P.6 (which sets the GAP+pts-tester wiring pattern).

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-29-prd-v1.2-pts-iut-design.md`](../specs/2026-05-29-prd-v1.2-pts-iut-design.md) — §11.8 P.7 row
- **auto-pts upstream** — https://github.com/auto-pts/auto-pts `doc/btp_gatt.txt` (authoritative)
- Phase 1 `IutActions` GATT methods — design spec §4 (notify/indicate/read/write)
- v1.0 GATT — `pybluehost/ble/gatt.py` (`GATTServer.add_service`, `GATTClient.read_characteristic` / `write_characteristic` / `discover_*`)

**Hard dependencies:**
- P.5 (BTP foundation) merged
- P.6 (GAP service + pts-tester wiring pattern) merged — P.7 follows the same registration / event pattern
- Phase 1 (`IutActions`) merged

**Scope discipline:**
- **No GATT signed write** (auth signature procedure — Core Spec §3.4.5.3). Optional, low-value for PTS conformance run-time.
- **No reliable / queued write** prepare/execute response inspection beyond pass/fail. The BTP `Write Reliable` opcode runs the prepare/execute pair; the BTP service doesn't expose the intermediate response data.
- **MTU exchange exposed but no automatic negotiation logic** — autoptsclient drives it explicitly per test case.
- **Attribute handle space**: BTP service uses 16-bit handles. The first attribute (database hash, primary service header) is handle 0x0001. The mapping between BTP-assigned handles and v1.0 GATT server internal handles is maintained per session.

```python
"""GATT BTP service — server + client handlers for autoptsclient.

See design spec §11.5 + auto-pts doc/btp_gatt.txt.
"""
from __future__ import annotations

import asyncio
import logging
import struct
from dataclasses import dataclass, field
from typing import TYPE_CHECKING

from pybluehost.pts.btp import opcodes as op
from pybluehost.pts.btp.protocol import BtpFrame
from pybluehost.pts.btp.services.base import BtpService

if TYPE_CHECKING:
    from pybluehost.pts.actions import IutActions
    from pybluehost.pts.btp.tester import BtpTester

logger = logging.getLogger(__name__)


@dataclass
class _DynamicAttribute:
    handle: int
    uuid: bytes                 # 2 or 16 bytes
    properties: int = 0         # for characteristics; descriptors use 0
    permissions: int = 0
    value: bytes = b""
    is_characteristic: bool = False
    is_descriptor: bool = False
    is_service: bool = False


@dataclass
class _DynamicService:
    handle: int
    uuid: bytes
    primary: bool
    attributes: list[_DynamicAttribute] = field(default_factory=list)


class GattService(BtpService):
    SERVICE_ID = op.SERVICE_GATT

    def __init__(self, *, actions: "IutActions", tester: "BtpTester | None" = None) -> None:
        self._actions = actions
        self._tester = tester
        self._next_handle = 0x0001
        self._services: list[_DynamicService] = []
        self._all_attrs: dict[int, _DynamicAttribute] = {}
        self._cccd_subscriptions: dict[int, set[int]] = {}    # conn_handle → set of char_handle subscribed

    def set_tester(self, tester: "BtpTester") -> None:
        self._tester = tester

    def _allocate_handle(self) -> int:
        handle = self._next_handle
        self._next_handle += 1
        return handle


def _encode_uuid_with_length_prefix(uuid_bytes: bytes) -> bytes:
    """Encode UUID with 1-byte length prefix (auto-pts wire format)."""
    if len(uuid_bytes) not in (2, 16):
        raise ValueError(f"GATT UUID must be 2 or 16 bytes, got {len(uuid_bytes)}")
    return bytes([len(uuid_bytes)]) + uuid_bytes


def _decode_uuid(data: bytes, offset: int) -> tuple[bytes, int]:
    """Decode `[uuid_len_u8, uuid_bytes]` starting at offset; return (uuid_bytes, new_offset)."""
    if offset >= len(data):
        raise ValueError("UUID field truncated")
    uuid_len = data[offset]
    if uuid_len not in (2, 16):
        raise ValueError(f"UUID length must be 2 or 16, got {uuid_len}")
    if offset + 1 + uuid_len > len(data):
        raise ValueError("UUID bytes truncated")
    return bytes(data[offset + 1:offset + 1 + uuid_len]), offset + 1 + uuid_len
```

Three handlers, each assigns and returns a 16-bit attribute handle.

**Add Service** (0x02) command body: `service_type (u8)` + `uuid_len (u8)` + `uuid_bytes (2|16)`. Response: `handle (u16 LE)`.

**Add Characteristic** (0x03) body: `parent_service_handle (u16 LE)` + `properties (u8)` + `permissions (u8)` + `uuid_len (u8)` + `uuid_bytes`. Response: `char_handle (u16 LE)` (the value handle; the declaration handle is char_handle − 1).

**Add Descriptor** (0x04) body: `parent_char_handle (u16 LE)` + `permissions (u8)` + `uuid_len (u8)` + `uuid_bytes`. Response: `desc_handle (u16 LE)`.

```python
        if service_type not in (op.GATT_SERVICE_PRIMARY, op.GATT_SERVICE_SECONDARY):
            return op.BTP_STATUS_FAILED, b""
        try:
            uuid, _ = _decode_uuid(data, offset=1)
        except ValueError:
            return op.BTP_STATUS_FAILED, b""
        handle = self._allocate_handle()
        svc = _DynamicService(
            handle=handle, uuid=uuid,
            primary=(service_type == op.GATT_SERVICE_PRIMARY),
        )
        attr = _DynamicAttribute(handle=handle, uuid=uuid, is_service=True)
        svc.attributes.append(attr)
        self._services.append(svc)
        self._all_attrs[handle] = attr
        return op.BTP_STATUS_SUCCESS, handle.to_bytes(2, "little")

    # ---- Add Characteristic ----------------------------------------------

    async def _handle_op_03(self, controller_index: int, data: bytes):
        if len(data) < 5:
            return op.BTP_STATUS_FAILED, b""
        parent_handle = int.from_bytes(data[0:2], "little")
        properties = data[2]
        permissions = data[3]
        try:
            uuid, _ = _decode_uuid(data, offset=4)
        except ValueError:
            return op.BTP_STATUS_FAILED, b""
        parent_svc = next((s for s in self._services if s.handle == parent_handle), None)
        if parent_svc is None:
            return op.BTP_STATUS_FAILED, b""
        # Allocate declaration handle (consumed but not returned) + value handle.
        decl_handle = self._allocate_handle()
        value_handle = self._allocate_handle()
        decl_attr = _DynamicAttribute(
            handle=decl_handle, uuid=b"\x03\x28",     # Characteristic Declaration UUID 0x2803
        )
        value_attr = _DynamicAttribute(
            handle=value_handle, uuid=uuid, properties=properties, permissions=permissions,
            is_characteristic=True,
        )
        parent_svc.attributes.extend([decl_attr, value_attr])
        self._all_attrs[decl_handle] = decl_attr
        self._all_attrs[value_handle] = value_attr
        return op.BTP_STATUS_SUCCESS, value_handle.to_bytes(2, "little")

    # ---- Add Descriptor ---------------------------------------------------

    async def _handle_op_04(self, controller_index: int, data: bytes):
        if len(data) < 4:
            return op.BTP_STATUS_FAILED, b""
        parent_handle = int.from_bytes(data[0:2], "little")
        permissions = data[2]
        try:
            uuid, _ = _decode_uuid(data, offset=3)
        except ValueError:
            return op.BTP_STATUS_FAILED, b""
        # Find the parent's owning service.
        parent_attr = self._all_attrs.get(parent_handle)
        if parent_attr is None or not parent_attr.is_characteristic:
            return op.BTP_STATUS_FAILED, b""
        # The descriptor goes into the same service the characteristic belongs to.
        parent_svc = next(
            (s for s in self._services if any(a.handle == parent_handle for a in s.attributes)),
            None,
        )
        if parent_svc is None:
            return op.BTP_STATUS_FAILED, b""
        desc_handle = self._allocate_handle()
        desc_attr = _DynamicAttribute(
            handle=desc_handle, uuid=uuid, permissions=permissions, is_descriptor=True,
        )
        parent_svc.attributes.append(desc_attr)
        self._all_attrs[desc_handle] = desc_attr
        return op.BTP_STATUS_SUCCESS, desc_handle.to_bytes(2, "little")
```

```python
    # ---- Set Value -------------------------------------------------------

    async def _handle_op_06(self, controller_index: int, data: bytes):
        if len(data) < 4:
            return op.BTP_STATUS_FAILED, b""
        handle = int.from_bytes(data[0:2], "little")
        value_len = int.from_bytes(data[2:4], "little")
        if 4 + value_len > len(data):
            return op.BTP_STATUS_FAILED, b""
        attr = self._all_attrs.get(handle)
        if attr is None:
            return op.BTP_STATUS_FAILED, b""
        attr.value = bytes(data[4:4 + value_len])
        # If the server is running and this is a characteristic value handle,
        # autoptsclient expects this to propagate to subscribers as a NOTIFY.
        # That side effect is handled separately by autoptsclient sending Notify
        # explicitly (opcode 0x1A); we don't auto-notify on Set Value.
        return op.BTP_STATUS_SUCCESS, b""

    # ---- Start Server ----------------------------------------------------

    async def _handle_op_07(self, controller_index: int, data: bytes):
        # Translate accumulated _services into v1.0 ServiceDefinition objects
        # and register each with the stack's GATT server.
        from pybluehost.ble.gatt import (
            CharacteristicDefinition, ServiceDefinition,        # adjust import paths
        )
        stack = getattr(self._actions, "_stack", None)
        if stack is None:
            logger.warning("GATT Start Server: actions has no _stack attribute")
            return op.BTP_STATUS_FAILED, b""

        for dyn_svc in self._services:
            chars: list = []
            current_char: _DynamicAttribute | None = None
            descriptors: list = []
            for attr in dyn_svc.attributes[1:]:    # skip the service declaration itself
                if attr.is_characteristic:
                    # Flush previous char's descriptors.
                    if current_char is not None:
                        chars.append(CharacteristicDefinition(
                            uuid=current_char.uuid, properties=current_char.properties,
                            permissions=current_char.permissions, value=current_char.value,
                            descriptors=descriptors,
                        ))
                        descriptors = []
                    current_char = attr
                elif attr.is_descriptor:
                    descriptors.append(attr)
            if current_char is not None:
                chars.append(CharacteristicDefinition(
                    uuid=current_char.uuid, properties=current_char.properties,
                    permissions=current_char.permissions, value=current_char.value,
                    descriptors=descriptors,
                ))
            stack.gatt_server.add_service(ServiceDefinition(
                uuid=dyn_svc.uuid, primary=dyn_svc.primary, characteristics=chars,
            ))
        return op.BTP_STATUS_SUCCESS, b""
```

```python
    def _resolve_conn_handle(self, addr: bytes) -> int | None:
        """Look up an active connection by peer address."""
        session = self._actions.status() if hasattr(self._actions, "status") else None

            if bytes(info.peer) == addr:
```

```python
    def _resolve_gatt_client(self, addr: bytes):
        """Look up the active LE connection's GATTClient by peer address."""
        session = self._actions.status() if hasattr(self._actions, "status") else None
        if session is None:
            return None
        for info in session.connections.values():
            if bytes(info.peer) == addr and getattr(info, "gatt_client", None) is not None:

        return None
```

```python
async def _read_frame(reader):
    header = await reader.readexactly(BTP_HEADER_SIZE)
    data_len = int.from_bytes(header[3:5], "little")
    body = await reader.readexactly(data_len) if data_len else b""
    return decode_btp_frame(header + body)


async def test_btp_gatt_add_service_returns_handle(unused_tcp_port):
    stack = await Stack.virtual()
    try:
        actions = IutActions(stack)
        reg = BtpServiceRegistry()
        reg.register(CoreService(registry=reg))
        gap = GapService(actions=actions); reg.register(gap)
        gatt = GattService(actions=actions); reg.register(gatt)
        tester = BtpTester(registry=reg, host="127.0.0.1", port=unused_tcp_port)
        await tester.start()
        gatt.set_tester(tester)
        try:
            reader, writer = await asyncio.open_connection("127.0.0.1", unused_tcp_port)
            await _read_frame(reader)        # READY event

            # Add Battery Service (UUID 0x180F).
            add_body = bytes([op.GATT_SERVICE_PRIMARY, 2]) + bytes.fromhex("0F18")
            writer.write(encode_btp_frame(BtpFrame(
                service=op.SERVICE_GATT, opcode=op.OP_GATT_ADD_SERVICE,
                controller_index=0, data=add_body,
            )))
            await writer.drain()
            resp = await _read_frame(reader)
            assert resp.data[0] == op.BTP_STATUS_SUCCESS
            # 2-byte handle in response after status byte
            handle = int.from_bytes(resp.data[1:3], "little")
            assert handle == 0x0001
            writer.close()
            await writer.wait_closed()
        finally:
            await tester.stop()
    finally:
        await stack.close()
```
