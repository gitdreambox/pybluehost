# v2.0 Plan A.6 — sounddevice + CLI Wrap-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire OS audio devices into PyBlueHost's Classic-audio CLI surface, add the two A2DP CLI commands that A.2 deferred, polish the AVRCP/HFP/HSP CLI commands with `--play` / `--mic` / `--device` flags, write the user runbook, and stamp v2.0 complete in STATUS.md.

**Architecture:** A single `pybluehost/audio/_sounddevice_io.py` wraps `python-sounddevice` with a **lazy import** (so users without the audio extras see a clear error, not a stack trace) plus an **asyncio-friendly ring buffer** bridging sounddevice's callback thread to the asyncio event loop. Each profile CLI command grows three flags: `--play=<file|sounddevice>` (where decoded PCM goes), `--mic=<file|sounddevice>` (where outbound PCM comes from), and `--device=<index>` (which sounddevice device to use). The 6 final CLI subcommands are: `a2dp-source` + `a2dp-sink` (new in A.6); `avrcp-control` + `avrcp-target` (extended from A.3); `hfp-test` + `hsp-test` (extended from A.4 / A.5).

**Tech Stack:** Python 3.10+, asyncio, **python-sounddevice ≥ 0.4** (new optional dep — `[audio]` extras), pytest with `asyncio_mode=auto`. No PortAudio-version pinning (sounddevice handles the C ABI).

**Spec references:**
- Design spec: [`docs/superpowers/specs/2026-05-27-prd-v2.0-classic-audio-design.md`](../specs/2026-05-27-prd-v2.0-classic-audio-design.md) — §3 Plan A.6 (lines 278-302), §5.3 OS audio errors (lines 484-490)
- PRD: [`docs/PRD-v2.0.md`](../../PRD-v2.0.md) §3.6 sounddevice scope, §3.7 small improvements
- **python-sounddevice docs** — https://python-sounddevice.readthedocs.io/

**Hard dependencies:**
- All of A.1-A.5 must be merged. A.6 only adds the audio device layer + final CLI polish.

**Scope discipline:**
- **Optional dependency**: sounddevice + PortAudio must be optional (`pip install pybluehost[audio]`). The core stack runs without them.
- **No format conversion**: A.6 assumes sounddevice's `samplerate` matches the codec's (44.1k for A2DP SBC, 8k for CVSD, 16k for mSBC). If user requests a mismatch, sounddevice errors — A.6 surfaces a clear CLI error, doesn't try to resample.
- **No real-time scheduling magic**: A.6 uses sounddevice's default RtAudio thread (high priority on its own). The asyncio side just consumes / produces from a `queue.Queue` (thread-safe).
- **`--play` and `--mic` accept either a file path or the literal string `sounddevice`**. No other values.

```python
"""sounddevice integration — lazy-import + asyncio bridge."""
from __future__ import annotations

import asyncio
import logging
import queue
import sys
from typing import Any

from pybluehost.core.errors import SnifferError      # reuse existing error base, or add a new one

logger = logging.getLogger(__name__)


class AudioDeviceUnavailableError(Exception):
    """Raised when sounddevice / portaudio is not installed."""


def try_import_sounddevice() -> Any:
    """Return the sounddevice module, or raise AudioDeviceUnavailableError.

    Lazy import so non-audio users never pay the PortAudio dependency.
    """
    mod = sys.modules.get("sounddevice")
    if mod is None:
        try:
            import sounddevice as mod
        except ImportError as e:
            raise AudioDeviceUnavailableError(
                "audio extras not installed: pip install 'pybluehost[audio]' "
                "(or use --play=<file> / --mic=<file> for file-based I/O)"
            ) from e
    if mod is None:
        raise AudioDeviceUnavailableError(
            "audio extras not installed: pip install 'pybluehost[audio]'"
        )
    return mod


class SoundDeviceInput:
    """Async wrapper around sounddevice.InputStream — yields PCM bytes."""

    def __init__(
        self, *, sample_rate: int, channels: int = 1, device: int | None = None,
        blocksize: int = 0, max_buffer_bytes: int = 1 << 20,
    ) -> None:
        self._sample_rate = sample_rate
        self._channels = channels
        self._device = device
        self._blocksize = blocksize
        self._sample_width = 2          # int16
        self._buffer = bytearray()
        self._buffer_cond = asyncio.Condition()
        self._max_buffer_bytes = max_buffer_bytes
        self._stream: Any | None = None
        self._loop: asyncio.AbstractEventLoop | None = None

    async def start(self) -> None:
        sd = try_import_sounddevice()
        self._loop = asyncio.get_running_loop()
        self._stream = sd.InputStream(
            samplerate=self._sample_rate, channels=self._channels,
            device=self._device, blocksize=self._blocksize,
            dtype="int16", callback=self._on_audio_thread,
        )
        self._stream.start()

    def _on_audio_thread(self, indata, frames, time_info, status) -> None:
        """Called from sounddevice's high-priority audio thread."""
        if status:
            logger.warning("SoundDeviceInput: stream status %s", status)
        # indata is a numpy (frames, channels) int16 array; flatten to bytes.
        pcm_bytes = bytes(indata.tobytes())
        asyncio.run_coroutine_threadsafe(self._enqueue(pcm_bytes), self._loop)

    async def _enqueue(self, pcm_bytes: bytes) -> None:
        async with self._buffer_cond:
            self._buffer.extend(pcm_bytes)
            if len(self._buffer) > self._max_buffer_bytes:
                # Drop oldest data to keep buffer bounded.
                overflow = len(self._buffer) - self._max_buffer_bytes
                del self._buffer[:overflow]
                logger.warning(
                    "SoundDeviceInput: buffer overflow; dropped %d bytes",
                    overflow,
                )
            self._buffer_cond.notify_all()

    async def read(self, *, n_bytes: int, timeout: float = 5.0) -> bytes:
        async def _wait():
            async with self._buffer_cond:
                while len(self._buffer) < n_bytes:
                    await self._buffer_cond.wait()
                out = bytes(self._buffer[:n_bytes])
                del self._buffer[:n_bytes]
                return out
        return await asyncio.wait_for(_wait(), timeout=timeout)

    async def stop(self) -> None:
        if self._stream is not None:
            try:
                self._stream.stop()
                self._stream.close()
            except Exception:
                logger.exception("SoundDeviceInput: stop failed")
            self._stream = None


class SoundDeviceOutput:
    """Async wrapper around sounddevice.OutputStream — accepts PCM bytes."""

    def __init__(
        self, *, sample_rate: int, channels: int = 1, device: int | None = None,
        blocksize: int = 0,
    ) -> None:
        self._sample_rate = sample_rate
        self._channels = channels
        self._device = device
        self._blocksize = blocksize
        self._queue: "queue.Queue[bytes]" = queue.Queue(maxsize=128)
        self._stream: Any | None = None
        self._loop: asyncio.AbstractEventLoop | None = None

    async def start(self) -> None:
        sd = try_import_sounddevice()
        self._loop = asyncio.get_running_loop()
        self._stream = sd.OutputStream(
            samplerate=self._sample_rate, channels=self._channels,
            device=self._device, blocksize=self._blocksize,
            dtype="int16", callback=self._on_audio_thread,
        )
        self._stream.start()

    def _on_audio_thread(self, outdata, frames, time_info, status) -> None:
        """Called from sounddevice's audio thread — pull PCM, fill outdata."""
        if status:
            logger.warning("SoundDeviceOutput: stream status %s", status)
        need_bytes = frames * self._channels * 2     # int16
        try:
            pcm = self._queue.get_nowait()
        except queue.Empty:
            outdata[:] = 0
            return
        # If we got less than needed, pad with zeros (audible underrun).
        if len(pcm) < need_bytes:
            pcm = pcm + bytes(need_bytes - len(pcm))
        import numpy as np
        outdata[:] = np.frombuffer(pcm[:need_bytes], dtype="int16").reshape(-1, self._channels)

    async def write(self, pcm_bytes: bytes) -> None:
        # Use the executor so we don't block the event loop if the queue is full.
        loop = asyncio.get_running_loop()
        await loop.run_in_executor(None, self._queue.put, pcm_bytes)

    async def stop(self) -> None:
        if self._stream is not None:
            try:
                self._stream.stop()
                self._stream.close()
            except Exception:
                logger.exception("SoundDeviceOutput: stop failed")
            self._stream = None
```

```python
"""Shared --play / --mic / --device parser + audio source/sink factory."""
from __future__ import annotations

import asyncio
import wave
from dataclasses import dataclass
from typing import Any


@dataclass(frozen=True)
class AudioSpec:
    kind: str               # "file" | "sounddevice"
    path: str | None = None
    device: int | None = None


def parse_audio_spec(arg: str) -> AudioSpec:
    if not arg:
        raise ValueError("--play/--mic: empty value")
    if arg == "sounddevice":
        return AudioSpec(kind="sounddevice", device=None)
    if arg.startswith("sounddevice:"):
        return AudioSpec(kind="sounddevice", device=int(arg.split(":", 1)[1]))
    return AudioSpec(kind="file", path=arg)


class _WavFileSource:
    """File-backed audio source returning successive chunks via read(n_bytes)."""

    def __init__(self, path: str, *, expected_sample_rate: int, expected_channels: int) -> None:
        self._wav = wave.open(path, "rb")
        if self._wav.getframerate() != expected_sample_rate:
            raise ValueError(
                f"WAV sample rate {self._wav.getframerate()} != "
                f"expected {expected_sample_rate}"
            )
        if self._wav.getnchannels() != expected_channels:
            raise ValueError(
                f"WAV channels {self._wav.getnchannels()} != expected {expected_channels}"
            )

    async def read(self, *, n_bytes: int, timeout: float = 5.0) -> bytes:
        loop = asyncio.get_running_loop()
        data = await loop.run_in_executor(None, self._wav.readframes, n_bytes // 2)
        # End of file → return empty bytes; caller treats as EOS.
        return data

    async def stop(self) -> None:
        self._wav.close()


class _WavFileSink:
    """File-backed audio sink — appends PCM via write(pcm_bytes)."""

    def __init__(self, path: str, *, sample_rate: int, channels: int) -> None:
        self._wav = wave.open(path, "wb")
        self._wav.setnchannels(channels); self._wav.setsampwidth(2)
        self._wav.setframerate(sample_rate)

    async def write(self, pcm: bytes) -> None:
        # Wave writeframes is blocking; run in executor.
        loop = asyncio.get_running_loop()
        await loop.run_in_executor(None, self._wav.writeframes, pcm)

    async def stop(self) -> None:
        self._wav.close()


def make_audio_source(
    spec: AudioSpec, *, sample_rate: int, channels: int,
) -> Any:
    if spec.kind == "file":
        return _WavFileSource(
            spec.path, expected_sample_rate=sample_rate,
            expected_channels=channels,
        )
    elif spec.kind == "sounddevice":
        from pybluehost.audio._sounddevice_io import SoundDeviceInput
        return SoundDeviceInput(
            sample_rate=sample_rate, channels=channels, device=spec.device,
        )
    else:
        raise ValueError(f"unknown AudioSpec kind: {spec.kind}")


def make_audio_sink(
    spec: AudioSpec, *, sample_rate: int, channels: int,
) -> Any:
    if spec.kind == "file":
        return _WavFileSink(spec.path, sample_rate=sample_rate, channels=channels)
    elif spec.kind == "sounddevice":
        from pybluehost.audio._sounddevice_io import SoundDeviceOutput
        return SoundDeviceOutput(
            sample_rate=sample_rate, channels=channels, device=spec.device,
        )
    else:
        raise ValueError(f"unknown AudioSpec kind: {spec.kind}")
```

import argparse

import logging

def register_a2dp_source_command(subparsers: argparse._SubParsersAction) -> None:
    p = subparsers.add_parser(
        "a2dp-source",
        help="Push PCM from a WAV file or microphone to a peer A2DP sink",
    )
    add_common_arguments(p)
    p.add_argument("--target", required=True, help="Peer BD address")
    p.add_argument("--mic", required=True,
                   help="PCM source: path to WAV file, or 'sounddevice'[:device]")
    p.add_argument("--device", type=int, default=None,
                   help="sounddevice device index (overrides --mic=sounddevice:N)")
    p.set_defaults(func=lambda args: asyncio.run(
        run_app_command(args.transport, _a2dp_source_main,
                        target=args.target, mic=args.mic, device=args.device,
                        **trace_kwargs_from_args(args))
    ))


async def _a2dp_source_main(stack, stop_event, *, target, mic, device):
    logger = logging.getLogger(__name__)
    from pybluehost.profiles.classic.a2dp import A2DPSource

    src = A2DPSource(stack=stack)
    stack.register_profile(src)

    await stack.gap.connect(target)
    session = await src.connect(peer_addr=target)
    cfg = await session.negotiate_codec(prefer=["SBC"])
    logger.info(
        "A2DP source negotiated: %d Hz / %s / blocks=%d / bitpool=%d",
        cfg.sample_rate, cfg.channel_mode, cfg.blocks, cfg.bitpool,
    )
    await session.start()

    # Build the audio source from --mic.
    spec = parse_audio_spec(mic)
    if device is not None:
        spec = parse_audio_spec(f"sounddevice:{device}")
    channels = 1 if cfg.channel_mode == "mono" else 2
    audio_src = make_audio_source(spec, sample_rate=cfg.sample_rate, channels=channels)
    if hasattr(audio_src, "start"):
        await audio_src.start()
    try:
        # Stream one SBC frame at a time.
        bytes_per_frame = 2 * cfg.blocks * cfg.subbands * channels
        try:
            while not stop_event.is_set():
                pcm = await audio_src.read(n_bytes=bytes_per_frame, timeout=5.0)
                if not pcm or len(pcm) < bytes_per_frame:
                    logger.info("A2DP source: end of input")
                    break
                await session.send_pcm(pcm)
        except asyncio.TimeoutError:
            logger.warning("A2DP source: timeout reading audio source")
    finally:
        await session.stop()
        if hasattr(audio_src, "stop"):
            await audio_src.stop()
```

"""`pybluehost app a2dp-sink` — accept A2DP streams from a peer, decode + play/save PCM."""
import argparse
import asyncio
import logging

from pybluehost.cli._audio_arg import make_audio_sink, parse_audio_spec
from pybluehost.cli._lifecycle import (
    add_common_arguments, run_app_command, trace_kwargs_from_args,
)


def register_a2dp_sink_command(subparsers: argparse._SubParsersAction) -> None:
    p = subparsers.add_parser(
        "a2dp-sink",
        help="Accept incoming A2DP streams and write/play decoded PCM (Ctrl+C to stop)",
    )
    add_common_arguments(p)
    p.add_argument("--play", required=True,
                   help="PCM sink: path to output WAV file, or 'sounddevice'[:device]")
    p.add_argument("--device", type=int, default=None)
    p.set_defaults(func=lambda args: asyncio.run(
        run_app_command(args.transport, _a2dp_sink_main,
                        play=args.play, device=args.device,
                        **trace_kwargs_from_args(args))
    ))


async def _a2dp_sink_main(stack, stop_event, *, play, device):
    logger = logging.getLogger(__name__)
    from pybluehost.profiles.classic.a2dp import A2DPSink

    sink = A2DPSink(stack=stack)
    stack.register_profile(sink)

    # We don't yet know the codec config until the source negotiates with us.
    # Open the audio sink lazily on first PCM frame, using config from SBC header.
    audio_sink_holder = []
    spec = parse_audio_spec(play)
    if device is not None:
        spec = parse_audio_spec(f"sounddevice:{device}")

    async def on_pcm(pcm: bytes) -> None:
        if not audio_sink_holder:
            # Lazy create — we infer rate/channels from sink's current config.
            # In practice, A.2's A2DPSink keeps a SBCDecoder; the first decoded
            # PCM tells us the config. For simplicity in A.6 we hardcode A2DP
            # default (44.1 kHz stereo) — real flexible mode requires A2DPSink
            # to surface negotiated config, which it can via the SBCHeader of
            # the first received frame.
            audio_sink = make_audio_sink(spec, sample_rate=44100, channels=2)
            if hasattr(audio_sink, "start"):
                await audio_sink.start()
            audio_sink_holder.append(audio_sink)
        await audio_sink_holder[0].write(pcm)

    sink.on_pcm(on_pcm)
    logger.info("A2DP sink ready; waiting for incoming source connection (Ctrl+C to stop)")
    await stop_event.wait()
    if audio_sink_holder:
        await audio_sink_holder[0].stop()
```

async def _avrcp_target_main(stack, stop_event):
    logger = logging.getLogger(__name__)
    from pybluehost.avctp.constants import AVCTP_PSM
    from pybluehost.avctp.session import AVCTPSession
    from pybluehost.profiles.classic.avrcp import AVRCPTarget

    target_holder: list = []

    async def _accept_avctp(channel):
        session = AVCTPSession(channel)
        t = AVRCPTarget(session=session, stack=stack)
        def _on_button(op_id, press):
            label = {
                0x44: "PLAY", 0x45: "STOP", 0x46: "PAUSE",
                0x4B: "FORWARD", 0x4C: "BACKWARD",
                0x41: "VOLUME_UP", 0x42: "VOLUME_DOWN", 0x43: "MUTE",
            }.get(op_id, f"0x{op_id:02X}")
            logger.info("AVRCP %s %s", label, "press" if press else "release")
        t.on_button(_on_button)
        target_holder.append(t)
        logger.info("AVRCP target attached to incoming controller")
    stack.l2cap.listen_classic_psm(AVCTP_PSM, _accept_avctp)

    logger.info("AVRCP target ready — listening on PSM 0x%04X", AVCTP_PSM)
    await stop_event.wait()
